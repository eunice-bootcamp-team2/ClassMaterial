1️⃣ 먼저 배포된 리소스 전부 삭제 (중요)
	계정을 바로 삭제하기 전에 **앱 / 머신 / Postgres**를 먼저 지워야 합니다.

✅ 1-1. 앱 삭제
```bash
fly apps list
```

삭제할 앱 확인 후:
```bash
fly apps destroy 앱이름
```

예:
```bash
fly apps destroy django-first2
```
⚠️ 이건 되돌릴 수 없음 (앱 + 배포 전부 삭제)

---
✅ 1-2. 머신 확인 (혹시 남아있을 경우)
```bash
fly machine list -a 앱이름
```

남아 있다면:
```bash
fly machine destroy 머신ID
```

---
✅ 1-3. Postgres(DB) 삭제 (있다면)
```bash
fly mpg list
```

삭제:
```bash
fly mpg destroy DB_ID
```

---
✅ 1-4. 리소스 최종 확인
```bash
fly apps list
fly mpg list
```
👉 **아무것도 안 나오면 정리 완료**
