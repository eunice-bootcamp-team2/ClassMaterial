🎯 목표
- Figma 화면 그대로 구현
- 데이터가 “실시간처럼 보이게” 만들기
- 지오펜스 + 알람 흐름 정상 동작

👉 눈에 보이는 완성이 목표

---
🧱 핵심 구성
```
Template + Chart.js + Leaflet  
        ↑  
     WebSocket  
        ↑  
    FastAPI (가짜 데이터)  
        ↓  
     Django (저장/판단)
```

---

🔧 1단계 작업 상세

---

1️⃣ 프론트 (대시보드 UI)

작업 내용
- Figma 기반 화면 구현
- Chart.js로 센서 그래프 표시
- 실시간 데이터 반영 (WebSocket)

완료 기준
- 페이지 로딩 시 그래프 정상 출력
- 데이터가 1초 단위로 갱신됨

---

2️⃣ 지도 + 지오펜스

작업 내용
- 공장 이미지 업로드
- Leaflet로 좌표계 구성
- 지오펜스 생성 UI (polygon)
- 센서 위치 표시

완료 기준
- 클릭으로 지오펜스 생성 가능
- 지도에 센서 표시

---

3️⃣ 가짜 데이터 생성 (핵심 ⭐)

작업 내용
- 센서 데이터 랜덤 생성
- 작업자 위치 랜덤 이동

```
센서값: 0 ~ 100  
좌표: x,y 랜덤 이동
```

완료 기준
- 데이터가 계속 변함
- UI에 반영됨

---

4️⃣ 실시간 통신

작업 내용
- FastAPI → WebSocket
- 프론트 연결

완료 기준
- 끊김 없이 데이터 수신

---

5️⃣ 지오펜스 판단 로직

작업 내용
- 서버에서 위치 포함 여부 판단
- 임계치 비교

```
if 위치 ∈ 지오펜스 AND 값 > 임계치:  
    알람
```

완료 기준
- 조건 만족 시 UI 알람 표시

---

6️⃣ 알람 UI

작업 내용
- 경고 색상
- 이벤트 리스트 표시

완료 기준
- 실시간 알람 발생 확인

---

🟢 1단계 결과물

✔ 대시보드 완성  
✔ 지도 + 지오펜스 동작  
✔ 센서 데이터 실시간 표시  
✔ 알람 발생 확인
