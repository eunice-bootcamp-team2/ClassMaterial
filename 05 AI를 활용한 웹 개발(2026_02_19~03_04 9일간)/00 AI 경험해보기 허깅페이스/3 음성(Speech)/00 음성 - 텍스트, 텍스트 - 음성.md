1️⃣ 음성 → 텍스트(STT)란 무엇인가?
STT(Speech To Text)는  
	사람이 말한 소리(음성)를 컴퓨터가 이해해서 글자(텍스트)로 바꿔주는 AI 기술입니다.

예를 들면:
- 오늘 회의 일정 알려줘
- 🤖 → 오늘 회의 일정 알려줘 (텍스트 변환)
    
즉, 귀로 듣는 걸 → 이해해서 → 글자로 적는 기술

|음성 입력|출력 텍스트|
|---|---|
|🇰🇷 “오늘 날씨 어때?”|오늘 날씨 어때?|
|🇺🇸 “How are you today?”|How are you today?|
✔️ 한국어음성은  한국어로 텍스트 출력
✔️ 영어음성은 영어로 텍스트 출력으로 언어가 그대로 유지됩니다.

---
2️⃣ STT는 어떻게 동작할까? (아주 쉽게)

복잡한 수학은 다 빼고 핵심 흐름만 보면
```
사람 음성
  ↓
소리 파형 (wav, mp3)
  ↓
AI 모델이 소리를 조각조각 분석
  ↓
발음 + 문맥 + 언어 패턴 추정
  ↓
문장(텍스트) 출력
```

AI는 사실 말을 이해한다기보다 이 소리 패턴 다음에는 이 글자가 올 확률이 높다를 계산합니다.

3️⃣ DRF에서 쓰기 좋은 모델 선택 기준 (중요 ⭐)

| 기준  | 추천                                   |
| --- | ------------------------------------ |
| STT | `openai/whisper-small`               |
| TTS | `kakao-enterprise/vits-korean` (실험용) |
| 서버  | CPU 가능 (small/base)                  |
| 배포  | Docker + 모델 캐싱 필수                    |
모델 캐싱이란 
AI / ML 모델은 보통:
- 로딩 시간이 김 (수 초 ~ 수십 초)
- 메모리 사용량 큼
- 매 요청마다 다시 로딩하면 성능 폭발적으로 나빠짐
    
그래서:
✔ 한 번 로드한 모델을  
✔ 메모리 또는 저장소에 유지하고  
✔ 재사용하는 전략이 필요

Redis는 캐싱을 구현하는 여러 방법 중 하나입니다. 즉 이미 계산한 결과를 저장해두고 재사용 하는 방식을 말합니다.

STT (Speech To Text) :사람의 음성(Speech)을 그대로 글자(Text)로 옮기는 기술 
- 이미 학습된 모델이 있음
- 파인튜닝 없어도 바로 사용 가능
- 평가도 단순 (잘 받아 적혔는지)

AI 입문자가 가장 먼저 해보기 좋은 단계입니다.

🔹 언제 쓰나?
- 회의 녹취
- 강의 자막
- 음성 메모
- 인터뷰 기록

STT + 번역 (영어 → 한국어)
이건 기술이 2개가 이어진 파이프라인입니다.
```
[1] STT (음성 → 영어 텍스트)
        ↓
[2] MT (영어 텍스트 → 한국어 텍스트)
```
	음성을 바로 번역하는 게 아니 음성 → 글자 → 번역 두 단계를 거침

|단계|결과|
|---|---|
|🇺🇸 음성|“I will join the meeting tomorrow.”|
|STT|I will join the meeting tomorrow.|
|번역|내일 회의에 참석하겠습니다.|
- STT 모델은 이미 완성도가 매우 높음
- 텍스트 번역 모델도 따로 잘 만들어져 있음
- 두 기술을 조합만 하면 됨
- AI 업계 실무에서도 제일 많이 쓰는 방식

난이도 ⭐⭐⭐☆☆
- 모델이 2개 필요
- 파이프라인 설계 필요
- 에러 원인도 2군데(STT 오류 / 번역 오류)
    
하지만 ❗
- 학습은 안 해도 됨
- 조립형 AI라 이해하기 쉬움

🔹 언제 쓰나?
- 영어 강의 → 한글 자막
- 해외 인터뷰 번역
- 글로벌 회의 요약
- 외국 영상 자막 자동 생성

###### 번역 목적 STT 파인튜닝이란?

번역용으로 STT를 파인튜닝하면,
- 사용자가 영어로 말했을 때
- 중간 변환 없이
- 바로 한국어 번역 결과가 출력됩니다.
```
영어 음성 → 한국어 텍스트
```
핵심 차이점:
- 영어 텍스트를 거치지 않습니다.

이 작업은 어렵습니다. 왜 어려울까?
1️⃣ 데이터가 특별함
- 학습 데이터가 일반 STT와 다릅니다.
- 입력: 영어음성 -> 정답: 한국어 번역문
- 이런 데이터는 구하기도, 만들기도 어렵습니다.

2️⃣ 평가가 복잡함 
- 음성 인식 정확도 (WER)
- 번역 품질 (BLEU, COMET)
- 두 가지를 동시에 검증해야 합니다.

3️⃣ 학습 비용이 큼
- GPU 사실상 필수
- 학습 시간 김
- 튜닝 난이도 높음

✅ 언제 사용하는 기술일까?
보통 다음과 같은 경우에 사용됩니다.
- 기업 연구
- 논문 / 실험 목적
- 특정 분야 전용 번역 시스템
- 대규모 서비스 최적화
- 개인 프로젝트에서는 거의 사용되지 않습니다.

번역용 STT는 파인튜닝은 가능하지만 데이터·평가·비용 측면에서 매우 어려운 작업입니다.
