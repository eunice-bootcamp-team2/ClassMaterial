엑셀·CSV 같은 표 데이터를 파이썬에서 다루기 쉽게 만들어주는 라이브러리

### 📊 판다스로 다루는 데이터는 어떤 모양?

판다스의 핵심 데이터 구조는 DataFrame(데이터프레임)입니다.
👉 DataFrame = 엑셀 시트 같은 표

|index|날짜|금액|카테고리|
|---|---|---|---|
|0|2024-01-01|10000|식비|
|1|2024-01-02|30000|교통|

- **행(row)** = 한 개의 기록
- **열(column)** = 변수(항목)
- **index** = 행 번호
    
---
📦 판다스 불러오기 (기본 문법)
```python
import pandas as pd
```

- `pandas` 이름이 길어서 보통 `pd`로 줄여 씀
- 이후 모든 판다스 기능은 `pd.`로 시작
    
---
🥇 1순위 (거의 매일 씀)

`df` = DataFrame의 줄임말  
→ 판다스에서 다들 그렇게 부를 뿐, 반드시 써야 하는 건 아니지만 너무 많이 쓰이기 때문에 코드는 보통 이런형태로 작성합니다.
```python
df.head() # 데이터의 앞부분(처음 5줄)을 보여줘 기본값 = 5줄
df.info() # 이 데이터의 요약 스펙을 보여줘
df["amount"] # amount라는 컬럼 하나만 꺼내줘
```

① `pd.read_csv()`
```python
df = pd.read_csv("data.csv")
```

→ CSV 파일을 DataFrame(표)로 불러온다

---
② `df.head()`
```python
df.head()
```

→ 데이터 앞부분 미리보기 (제대로 불러왔는지 확인)

왜 쓰나?
- 데이터가 제대로 불러와졌는지 확인
- 컬럼 이름 확인
- 값 형태(숫자/문자/날짜) 감 잡기
    
📌 기본값 = 5줄 `df.head(10)  # 앞 10줄`

---
③ `df.shape`
```python
df.shape
```

→ 데이터 크기 확인 (행, 열)

결과는?
- 표(DataFrame) ❌
- 한 줄짜리 데이터 묶음(Series) ⭕
    
📌 쉽게 말하면:
> 엑셀에서 한 열만 선택한 것

---
④ `df.columns`
```python
df.columns
```

→ 이 데이터에 어떤 컬럼(열)들이 있는지 전부 보여줘

결과 예시
```
Index(['날짜', '금액', '카테고리'], dtype='object')
```

언제 쓰나?
- 컬럼 이름이 헷갈릴 때
- 오타 때문에 에러 날 때
- 어떤 열을 선택할 수 있는지 확인할 때
    
📌 컬럼 선택 전에 거의 항상 확인

---
⑤ `df.info()`
```python
df.info()
```

→ 컬럼, 결측치, 타입 한 번에 확인 (무조건 찍어봄)

보여주는 것
- 행 개수
- 컬럼 개수
- 컬럼 이름
- 데이터 타입 (int, float, object 등)
- 비어있는 값(결측치) 여부
    
실무/연습에서:
> CSV 불러오면 무조건 info()부터 찍음

---
🥈 2순위 (분석 시작 단계)

⑥ 컬럼 선택
```python
df["금액"]  # 금액이라는 열 하나만 꺼내줘
df[["날짜", "금액"]]  # 날짜와 금액 두 개 열만 골라서 새 표로 만들어줘
```

→ 필요한 열만 뽑기
- `df["금액"]`엑셀에서 한 열만 클릭한 느낌
- `df[["날짜", "금액"]]` 엑셀에서 여러 열 드래그한 느낌

---
⑦ 조건 필터링
```python
df[df["금액"] > 10000]
```

→ 조건에 맞는 행만 선택

뜻 `금액`이 10000보다 큰 행만 골라줘

어떻게 동작하나?
1️⃣ `df["금액"] > 10000`  
→ 각 행마다 **True / False** 생성

2️⃣ `df[조건]`  
→ True인 행만 남김

📌 엑셀에서 필터 버튼 누른 것과 동일

예시 (여러 조건)
```python
df[(df["금액"] > 10000) & (df["카테고리"] == "식비")]
```

- `&` : 그리고
- `|` : 또는
    
⚠️ `and / or` ❌ → 반드시 `& / |` 사용

---
⑧ 정렬
```python
df.sort_values("날짜")
```

→ 특정 컬럼 기준 정렬

뜻 `날짜` 컬럼 기준으로 정렬해줘

기본 동작
- 오름차순 (과거 → 최근)
```python
df.sort_values("날짜", ascending=False)
```
→ 내림차순 (최근 → 과거)

원본 df는 변하지 않음
```python
df.sort_values("날짜", inplace=True)
```
→ 원본 자체 정렬

---
⑨ 타입 변환 (시계열 핵심)
```python
df["날짜"] = pd.to_datetime(df["날짜"])
```

→ 문자열 날짜 → 시간 데이터

뜻 : 문자열로 되어 있는 날짜를 파이썬이 이해하는 시간 데이터로 바꿔줘

왜 필요?
문자 상태:
```
"2024-01-10" < "2024-01-2"  ❌
```

시간 데이터:
```
2024-01-02 < 2024-01-10 ⭕
```

👉 시계열 분석은 무조건 시간 타입 필요

---
🥉 3순위 (실전에서 자주)

⑩ 인덱스 설정
```python
df.set_index("날짜", inplace=True)
```

→ 날짜를 시간 축 기준으로 설정

뜻: `날짜` 컬럼을 이 표의 기준축(인덱스)으로 바꿔줘

왜 쓰나?
- 시간 기준 정렬
- 시계열 분석 가능
- `resample`, `rolling` 사용 가능

📌 엑셀에서  
→ “이 열을 기준으로 정렬/참조하겠다”와 같음

---
⑪ 결측치 확인
```python
df.isna().sum()
```

→ 비어있는 값 개수 확인

뜻: 각 컬럼마다 비어있는 값이 몇 개인지 알려줘

어떻게 동작하나?

1️⃣ `df.isna()` → 비어있으면 True  
2️⃣ `sum()` → True 개수 세기

📌 실무에서는 무조건 확인하고 시작

---
⑫ 결측치 처리
```python
df.dropna()  # 비어있는 값이 있는 행을 통째로 제거
df.fillna(0) # 비어있는 값을 0으로 채움
```

→ 비어있는 값 제거 / 채우기

뜻: 비어있는 값이 있는 행을 통째로 제거**
📌 데이터가 많을 때 사용

뜻: 비어있는 값을 0으로 채움**
📌 금액, 수량처럼 **0이 의미 있을 때만 사용**

---
⑬ 기본 통계
```python
df.describe()
```

→ 평균, 최대, 최소 한 번에 확인

뜻: 숫자 컬럼의 기본 통계를 한 번에 계산**

보여주는 것
- 개수(count)
- 평균(mean)
- 표준편차(std)
- 최소값(min)
- 최대값(max)

📌 “데이터가 정상적인지” 감 잡는 용도

---
🏅 4순위 (시계열 연습에서 필수)

⑭ 리샘플링
```python
df.resample("D").mean()
```

→ 시간 단위 변경 (분 → 일, 일 → 월)

뜻: 시간 단위를 다시 묶어서 계산해줘**
- 분 → 일
- 일 → 월
- 시간 → 주

📌 날짜가 인덱스일 때만 가능

|코드|의미|
|---|---|
|`"D"`|하루|
|`"W"`|주|
|`"M"`|월|
|`"H"`|시간|
예시
```python
df.resample("M").sum()
```

→ 월별 합계

---
⑮ 이동 평균
```python
df["금액"].rolling(7).mean()
```

→ 7일 이동 평균

뜻: 최근 7일 값을 평균 내서 부드럽게 만들어줘

왜 쓰나?
- 노이즈 제거
- 추세 확인
- 이상치 감지

📌 결과 앞부분은 NaN 발생 (7일 모이기 전)

예시
```python
df["7일평균"] = df["금액"].rolling(7).mean()
```

---
⑯ 시프트 (전날 비교)
```python
df["전날금액"] = df["금액"].shift(1)
```

→ 이전 시점 값 가져오기

뜻: 한 칸 위(이전 시점)의 값을 가져와서 붙여줘

주 용도
- 전날 대비 변화
- 증감률 계산
- 이상 거래 탐지

예시 (증감 계산)
```python
df["변화량"] = df["금액"] - df["금액"].shift(1)
```

🔁 세 개를 같이 쓰면 이런 분석 가능
```python
df["7일평균"] = df["금액"].rolling(7).mean()
df["전날금액"] = df["금액"].shift(1)
df["증감"] = df["금액"] - df["전날금액"]
```

👉 추세 + 변화 + 비교 한 번에

---
🧠 핵심 기억 포인트
```
시간 묶기 → resample()
부드럽게 → rolling()
이전값 비교 → shift()
```

---
🎯 5순위 (데이터 정리 마무리)

⑰ 컬럼 이름 변경
```python
df.rename(columns={"amt": "금액"}, inplace=True)
```

뜻: 컬럼 이름 `amt`를 `금액`으로 바꿔줘**

언제 쓰나?
- 컬럼명이 이상할 때
- 영어 → 한글
- 오타 수정

📌 `inplace=True`  
→ 원본 df를 **바로 수정**

---
⑱ 컬럼 생성
```python
df["고액여부"] = df["금액"] > 100000
```

뜻: 조건 결과로 새로운 컬럼을 만든다**

- True / False 값 생성
- 분석용 파생 컬럼

📌 엑셀에서 수식 열 추가한 것과 동일

예시 (라벨 만들기)
```python
df["등급"] = df["금액"].apply(lambda x: "고액" if x > 100000 else "일반")
```

---
⑲ 그룹 집계
```python
df.groupby("카테고리")["금액"].sum()
```

뜻: 카테고리별로 묶어서 금액 합계를 계**

어떻게 읽나?
- `groupby("카테고리")` → 묶고
- `["금액"]` → 이 컬럼만 보고
- `.sum()` → 합계

📌 엑셀의 피벗 테이블과 동일

예시
```python
df.groupby("카테고리")["금액"].mean()
```

---
⑳ CSV로 저장
```python
df.to_csv("result.csv", index=False)
```

뜻: 지금까지 작업한 데이터를 CSV 파일로 저장

옵션 설명
- `"result.csv"` → 파일명
- `index=False` → 인덱스 번호 제외
    
📌 결과물 제출 / 공유 / 백업용

---
🔁 이 4개를 같이 쓰는 흐름

```python
df.rename(columns={"amt": "금액"}, inplace=True)
df["고액여부"] = df["금액"] > 100000
summary = df.groupby("카테고리")["금액"].sum()
df.to_csv("clean_data.csv", index=False)
```

👉 정리 → 분석 → 저장

```
read_csv → head → info → columns → shape

→ to_datetime → set_index
→ resample / rolling / shift
```
