### 📌 보충 설명: 가중치(Weight)란?

가중치란 무엇일까요?
👉 단어마다 주는 영향력 점수

가중치(weight)는  
각 단어가 결과에 얼마나 영향을 주는지를 나타내는 숫자예요.

쉽게 말하면,

> 이 단어는 감정을 판단할 때 얼마나 중요한 역할을 할까? 를 숫자로 표현한 것입니다.


예로 이해해볼게요

아래 문장을 보면,
```
"This movie is great"
```

모든 단어가 같은 역할을 할까요?  
아니죠.
- great → 강한 긍정 표현
- movie → 중립적인 정보
- is → 감정과 거의 무관
    

그래서 모델은 이렇게 생각합니다.
- `great` → 영향력 큼 (가중치 ↑)
- `movie`, `is` → 영향력 작음 (가중치 ↓)
    
👉 이 영향력의 크기가 바로 가중치예요.

---
가중치는 왜 필요할까요?

만약 모든 단어를 똑같이 취급한다면,
- 중요한 단어도
- 의미 없는 단어도
    
모두 같은 힘을 가지게 됩니다.

그러면 모델은  
👉 어떤 단어가 감정을 결정하는지 구분하지 못해요.

그래서
- 감정에 중요한 단어 → 가중치 크게
- 감정과 상관없는 단어 → 가중치 작게 이렇게 차이를 둡니다.

---
머신러닝·딥러닝에서 가중치의 역할

머신러닝이든 딥러닝이든 학습의 핵심은 결국 가중치를 잘 정하는 것이에요.

조금 더 쉽게 말하면,

> 어떤 단어를 더 믿을지,  
> 어떤 단어는 거의 무시할지를  
> 자동으로 배우는 과정

이 바로 모델 학습입니다.

---
딥러닝에서 말하는 학습이란?

딥러닝에서 학습이란,
- 처음에는 가중치를 아무렇게나 정해두고
- 결과가 틀리면
- 가중치를 조금씩 조정하면서
- 점점 더 잘 맞게 만드는 과정이에요.
    
즉, 딥러닝 학습 = 가중치를 자동으로 조정하는 과정입니다.

---
한 줄로 핵심만 정리하면

> 가중치는  
> 이 단어가 결과에 얼마나 영향을 주는지 나타내는 점수이고,  
> 모델 학습이란  
> 이 점수들을 점점 더 잘 맞게 조정해가는 과정입니다.

---
핵심 기억 포인트
- 가중치 = 영향력 점수
- 중요한 단어일수록 가중치 ↑
- 학습 = 가중치 조정
- 잘 학습된 모델 = 가중치가 잘 정리된 모델

---
###### 예시:
| 단어       | 문장에 포함 여부 (0/1) | 가중치  |
| -------- | --------------- | ---- |
| great    | 1               | +2.5 |
| product  | 1               | +0.5 |
| the      | 1               | 0.0  |
| terrible | 0               | -3.0 |
계산 방법:
- 문장을 벡터로 표현하면: `[1, 1, 1, 0]`  
- 각 단어의 벡터 값 × 가중치 값을 곱해서 다 더합니다:
```python
= (1 × 2.5)  +  (1 × 0.5)  +  (1 × 0.0)  +  (0 × -3.0)
= 2.5 + 0.5 + 0.0 + 0.0
= 3.0
```
점수(3.0)가 양수(+)면 긍정, 음수(-)면 부정이라고 판단합니다.

가중치 숫자의 기준은?
- 모델이 학습(훈련) 하면서 자동으로 결정해요.
- 자주 나오는 단어라고 해서 무조건 높지는 않아요.
- 긍정 문장에서 많이 나왔는지, 부정 문장에서 많이 나왔는지를 보고 결정해요.

|단어|긍정에 자주 등장|부정에 자주 등장|결과 가중치|
|---|---|---|---|
|love|많이|거의 없음|+3.0|
|bad|거의 없음|자주 등장|-2.5|
|product|양쪽에서 비슷하게|비슷하게|0.0|
