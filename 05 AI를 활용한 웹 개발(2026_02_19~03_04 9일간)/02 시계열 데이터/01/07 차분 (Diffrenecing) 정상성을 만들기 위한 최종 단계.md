앞 단계에서 우리는 다음을 시도했습니다.
- 05 정상성 변환 (Log / Box-Cox) → ❌ 실패
- 06 계절성 분해 (Classical / STL) → ❌ 실패
    
계절성을 제거해도 ADF 검정에서 p-value가 0.05보다 크게 나왔습니다.

즉, 비정상의 원인은 계절성이 아니라 추세(Trend)였습니다.

그래서 이제 마지막 단계인  
➡ 차분(Differencing)으로 넘어갑니다.

차분이란 무엇인가요?
차분은 아주 간단한 개념입니다.
```
차분 = 현재 값 − 이전 값
```
즉,
- 가격 자체를 보는 것이 아니라
- 가격의 변화량을 보는 것입니다.

| 날짜  | 시가     |
| --- | ------ |
| 어제  | 59,000 |
| 오늘  | 60,000 |
위의 표를 기준으로 차분값 = +1,000
즉 
❌ 오늘 가격이 얼마인가  
⭕ 어제보다 얼마나 변했는가 를 분석 대상으로 삼습니다.


왜 차분을 하면 정상성이 생기나요?
비정상 시계열의 가장 큰 원인은 추세(Trend)입니다.

차분을 하면:
1️⃣ 장기 상승/하락 추세가 제거됩니다.  
2️⃣ 평균이 일정해집니다.  
3️⃣ 분산이 안정됩니다.

```
비정상 (추세 존재)
   ↓
차분
   ↓
평균이 0 근처에서 흔들림
   ↓
정상성 만족 가능성 ↑
```
즉, 특히 주가 데이터는 가격보다 변화량이 훨씬 정상적인 특성을 보입니다.

# ---------------------------------------------------------

# ---------------------------------------------------------
# - p-value <= 0.05  → 정상성(O) → ARIMA 등 적용 가능
# - p-value >  0.05  → 정상성(X) → 다음 변환으로 이동
#
# 실무 팁:

### 전체 코드 : 차분(Differencing) + 정상성 재검정
```python
# =========================================================
# 07 차분(Differencing)으로 정상성(ADF) 만들기 (Skeleton 패턴 순서 그대로)
# (0) 준비 → (0-1) ADF 출력 헬퍼 → (1) 원본 시계열 →
# (2) 1차 차분 → (2-1) 시각화 → (2-2) ADF →
# (3) 2차 차분(필요 시) → (3-1) 시각화 → (3-2) ADF → (4) 판단
# =========================================================

# ---------------------------------------------------------
# (0) 준비: 라이브러리 불러오기
# ---------------------------------------------------------
import plotly.express as px
from statsmodels.tsa.stattools import adfuller


# ---------------------------------------------------------
# (0-1) ADF(정상성) 결과를 보기 좋게 출력하는 헬퍼 함수
# ---------------------------------------------------------
def check_stationarity(series, name="data"):
    result = adfuller(series.dropna())
    print(f"[{name}] ADF Statistic :", result[0])
    print(f"[{name}] p-value       :", result[1])
    print("-" * 40)
    return result



# ---------------------------------------------------------
# (1) 원본 시계열 준비 (+ 원본 정상성 확인: 선택)
# ---------------------------------------------------------
# 전제: df2에는 최소한 아래 컬럼이 있어야 함
# - df2["Date"] : 날짜(datetime)
# - df2["시가"] : 값(주가 시가)
ts = df2["시가"]

# (선택) 원본이 정상성인지 먼저 확인
res_original = check_stationarity(ts, "original")


# ---------------------------------------------------------
# (2) 1차 차분 수행 (기본 카드)
# ---------------------------------------------------------
# diff() : 현재 값 - 이전 값
# 예) 6/12 시가 - 6/11 시가
df2["시가_diff"] = ts.diff()
ts_diff1 = df2["시가_diff"]

# ---------------------------------------------------------
# (2-1) 1차 차분 결과 시각화 (선택)
# ---------------------------------------------------------
px.line(df2, x="Date", y="시가_diff", title="1st Difference")


# ---------------------------------------------------------
# (2-2) 1차 차분 정상성 검정(ADF)
# ---------------------------------------------------------
res_diff1 = check_stationarity(ts_diff1, "diff1")
# 해석:
# p-value <= 0.05  → 정상성(O)
# p-value  > 0.05  → 정상성(X) → 2차 차분 등 추가 시도


# ---------------------------------------------------------
# (3) 2차 차분 (1차로 부족할 때만)
# ---------------------------------------------------------
# diff(2) : 현재 값 - 2시점 이전 값
df2["시가_diff2"] = ts.diff(2)
ts_diff2 = df2["시가_diff2"]

# ---------------------------------------------------------
# (3-1) 2차 차분 결과 시각화 (선택)
# ---------------------------------------------------------**
px.line(df2, x="Date", y="시가_diff2", title="2nd Difference")

# ---------------------------------------------------------
# (3-2) 2차 차분 정상성 검정(ADF)
# ---------------------------------------------------------
res_diff2 = check_stationarity(ts_diff2, "diff2")


# ---------------------------------------------------------
# (4) 판단(해석 기준)
# ---------------------------------------------------------
# - p-value <= 0.05 : 정상성 통과 → ARIMA 같은 시계열 모델 적용 가능
# - p-value >  0.05 : 여전히 비정상 → 계절 차분/로그+차분/수익률 등 다음 단계 고려
```

그래서 변화량(1차 차분)에서 한 번 더 변화량을 뽑아  
➡️ 더 강하게 추세를 제거하려는 방법이 2차 차분(Second Difference) 입니다.

2차 차분은 차분을 한 번 더 하는 것입니다.

다만, 지금 코드처럼 `diff(2)`를 쓰면 의미는 이렇게 됩니다.
```
diff(2) = 현재값 − 2시점 전 값
```
즉 바로 전날이 아니라 이틀 전(2칸 전)과 비교하는 차이입니다.


(3) 2차 차분 (1차로 부족할 때만)
```python
df2["시가_diff2"] = ts.diff(2)
ts_diff2 = df2["시가_diff2"]
```

(1) `ts.diff2` 의미
- `diff()` 기본은 `diff(1)` → 현재 − 바로 이전
- `diff(2)` 는 → **현재 − 2개 이전**

###### 예를 들어:
| 시점  | 시가     |
| --- | ------ |
| t-2 | 50,000 |
| t-1 | 51,000 |
| t   | 49,500 |

- 1차 차분: `t - (t-1)` = 49,500 - 51,000 = 1,500
- 2차(diff(2)): `t - (t-2)` = 49,500 - 50,000 = 500

즉 `diff(2)`는 2칸 전과의 변화량을 만드는 것입니다.


(2) `df2["시가_diff2"] = ...` 의미
- 2차 차분 결과를 df2에 새 컬럼으로 저장합니다.
- 그래프 그리거나, ADF 검정할 때 편하게 쓰려고 저장하는 것입니다.

(3) `ts_diff2 = df2["시가_diff2"]` 의미
- 방금 만든 2차 차분 컬럼을 변수로 꺼내서
- ADF 검정 함수에 바로 넣기 쉽게 만든 것입니다.
