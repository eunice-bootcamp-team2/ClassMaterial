3 시계열 분석의 첫 단계: 시간 컬럼 정리

❓ 지금 우리가 부딪힌 문제는?
거래 데이터에는 거래가 발생한 정확한 시각이 `Datetime` 컬럼에 들어 있습니다.
예시
```
2024-06-14 22:00:10
2024-05-20 20:39:57
....
```
이 값은 날짜 + 시간이 함께 섞여 있는 형태입니다.

🚨 왜 이게 문제일까?
우리는 지금 이런 질문을 하고 싶습니다.
- 하루에 이상 거래가 몇 건 발생했을까?
- 어느 날짜에 이상 거래가 많았을까?
    
하지만 `Datetime`을 그대로 사용하면:
- `2024-06-14 22:00:10`
- `2024-05-20 20:39:57`
    
👉 같은 날인데도 서로 다른 값으로 인식됨  
👉 하루 단위로 묶어서 계산하기가 어려움

즉, 하루 단위 분석을 하려면 시간이 오히려 방해가 됩니다.


✅ 해결 방법: 날짜만 따로 분리하기
```python
df1['Date'] = pd.to_datetime(df1['Datetime']).dt.date
df1.head(2)
```
Datetime 컬럼을 날짜 타입으로 변환한 뒤, 날짜 부분만 추출해서 Date 컬럼에 저장

날짜 속성들
```python
# 연도 추출 (YYYY)  
.dt.year  
  
# 월 추출 (1 ~ 12)  
.dt.month  
  
# 일 추출 (해당 월의 날짜)  
.dt.day  
  
# 시(hour) 추출 (0 ~ 23)  
.dt.hour  
  
# 분(minute) 추출 (0 ~ 59)  
.dt.minute  
  
# 초(second) 추출 (0 ~ 59)  
.dt.second  
  
# 요일 이름 추출 (문자열) → Monday, Tuesday ...  
.dt.day_name()  
  
# 요일 숫자 추출 → 월요일=0, 일요일=6  
.dt.weekday  
  
# 날짜만 추출 (시간 제거) → YYYY-MM-DD  
.dt.date
```

```

```

문제 1
	데이터를 불러온 뒤, 일자(Date)별로 이상 거래의 합계를 계산하고 가장 이상 거래가 많이 발생한 날짜를 확인하시오.

풀이 핵심 요약
1️⃣ 데이터 불러오기  
2️⃣ Date컬럼에서 날짜 기준 정리  
3️⃣ 날짜별 이상거래 합계  
4️⃣ 최대값 날짜 확인

이건 시계열 분석의 정석 순서입니다.

---
1️⃣ 데이터 불러오기 
```python
df1 = pd.read_csv('25_FDS_bank.csv')
```

---
2️⃣ Datetime 컬럼을 날짜(Date)로 변환
```python
df1['Date'] = pd.to_datetime(df1['Datetime']).dt.date
```

---
3️⃣ 날짜별 이상거래 합계 
```python
df1.pivot_table(  
	index='Date',  
	values='이상거래여부',  
	aggfunc='sum'  
)
```

pivot_table은?
기준이 되는 컬럼으로 데이터를 묶어서, 숫자를 요약(집계)해주는 함수입니다.


1️⃣ `index='Date'`
- 데이터를 날짜(Date) 기준으로 묶겠다

2️⃣ `values='이상거래여부'`
- 계산에 사용할 값은  👉 `이상거래여부` 컬럼

3️⃣ `aggfunc='sum'`  : aggregation function
- 묶인 데이터들을 어떻게 계산할 것인지 지정하는 옵션  👉 합계(sum)를 구하겠다
    
다시 말해,
> 같은 날짜에 발생한 거래들의 이상거래여부(0/1)를 전부 더해라

이 코드가 실제로 하는 일 (말로 풀면)
> 같은 날짜(Date)끼리 거래를 묶은 뒤, 그 날짜에 발생한 이상 거래(1)가 총 몇 건인지 계산한다.

	날짜에 따라 이상 거래가 어떻게 변하는지를 이체 방식별로 나누어 확인하고자 합니다.

문제를 정리하면:
1️⃣ 데이터에서 날짜만 추출합니다.
2️⃣ 이체 방식별로 구분 -> `Date + 이체방식` 기준으로 이상 거래 건수(합계) 집계
3️⃣ 구분한 결과를 그래프로 표현 -> 집계 결과를 이체 방식별 색상으로 Line Chart 시각화

---
1️⃣ Datetime 컬럼에서 날짜만 추출해서 Date라는 새 컬럼에 저장 (이미 1번문제에 작성한 코드)

p1 = df1.pivot_table(
    index=['Date','이체방식'],
    values='이상거래여부',

③ `aggfunc='sum'`
- 0/1 값을 더해서 이상 거래 건수로 만들겠다

④ `.reset_index()` : 묶인 결과를 일반 컬럼 형태로 변환

- 전체 데이터 중에서
- 사용자가 선택한 이체 방식인 행만 True
- 나머지는 False
    
즉, 이체 방식이 AT인 거래만 표시한 조건표

4️⃣ 선택한 이체 방식의 일자별 이상 거래 합계 계산
```python
p2 = df1.loc[cond1].pivot_table(
    index='Date',
    values='이상거래여부',
    aggfunc='sum'
).reset_index()
```

1. `df1.loc[cond1]`
    - 선택한 이체 방식의 거래만 남김
2. `.loc` = label-based indexer (라벨 기반 선택 도구)
	- 행은 조건으로
	- 열은 이름으로 데이터를 골라내는 도구
	- 기본형태: `df.loc[행조건, 열이름]`
3. `index='Date'`
    - 날짜(Date) 기준으로 묶음
4. `values='이상거래여부'`
    - 이상 거래 여부(0/1)를 계산 대상으로 사용
5. `aggfunc='sum'`
    - 1의 개수를 더해서  
        → 날짜별 이상 거래 건수 계산

이상 거래 데이터 분석 = 실시간 센서 데이터에서 이상 징후를 시간 기준으로 정리·탐색하는 기본 틀입니다.

###### 1️⃣ 개념 대응부터 보기 (거래 → 센서)
|이상 거래 분석|실시간 센서 데이터|
|---|---|
|거래 1건|센서 측정 1회|
|Datetime|센서 측정 시각|
|Date|측정 날짜|
|이상거래여부(0/1)|이상 상태 여부(0/1)|
|이체 방식|센서 종류 / 위치 / 장비 ID|

---
2️⃣ 문제 1 → 센서 데이터에서의 활용

거래 분석 문제 1
> “날짜별로 이상 거래가 몇 건 발생했는가?”

센서 데이터로 바꾸면
> 날짜별로 센서 이상 값이 몇 번 발생했는가?

예시
- 공장 가스 센서 (CO, H₂S)
- 기준 초과 시 → `이상여부 = 1`
```python
# 날짜별 센서 이상 발생 횟수
sensor_df.pivot_table(
    index='Date',
    values='이상여부',
    aggfunc='sum'
)
```
활용
- 특정 날짜에 이상 알람이 몰렸는지
- 설비 점검이 필요한 날 찾기
---
3️⃣ 문제 2 → 센서 데이터에서의 활용

거래 분석 문제 2
> 이체 방식별로, 시간에 따라 이상 거래가 어떻게 변하는가?

센서 데이터로 바꾸면
> 센서 종류(또는 위치)별로, 시간에 따라 이상 징후가 어떻게 변하는가?

예시
- 센서 종류: `CO`, `H2S`, `Temperature`
- 색상 = 센서 종류
```python
sensor_pivot = sensor_df.pivot_table(
    index=['Date', '센서종류'],
    values='이상여부',
    aggfunc='sum'
).reset_index()

px.line(sensor_pivot, x='Date', y='이상여부', color='센서종류')
```
활용
- 어떤 센서가 항상 문제를 일으키는지
- 특정 기간에 특정 센서만 급증했는지
- 설비/라인별 위험 패턴 비교

---
문제 3 → 센서 데이터에서의 활용 (가장 중요)

거래 분석 문제 3
> 특정 이체 방식 하나를 골라 집중 분석

센서 데이터로 바꾸면
> 특정 센서 하나를 골라서 시간 흐름에 따른 이상 패턴을 집중 분석

예시
- 사용자 선택: `CO 센서`
```python
cond = (sensor_df['센서종류'] == 'CO')

co_daily = sensor_df.loc[cond].pivot_table(
    index='Date',
    values='이상여부',
    aggfunc='sum'
).reset_index()

px.line(co_daily, x='Date', y='이상여부')
```
활용
- CO 센서에서 이상 알람이 증가하는 추세인지
- 특정 날짜에 급격한 Spike 발생 여부
- 실제 사고 전조 신호 탐지

---
실시간 센서에서 특히 중요한 포인트
이상 거래 분석에서 배운 개념들이 센서 데이터에서는 이렇게 바로 쓰입니다 

✅ (1) Level (수준)
- 평소 하루 평균 이상 알람 수
- 기준보다 계속 높아지면 위험 신호
    
✅ (2) Trend (추세)
- 시간이 갈수록 이상 발생이 증가/감소
- 설비 노후화, 환경 변화 신호
    
✅ (3) Spike (급증)
- 갑작스러운 이상 폭증
- 즉시 알람 & 대응 필요

🧠 공통 핵심 구조 (이게 제일 중요)

모든 분야가 사실 같은 구조를 가지고 있어요.
```
시간 (Datetime / Date)
+ 대상 (거래, 센서, 사용자, 장비, 서버)
+ 이상 여부 (0 / 1)
→ 시간 기준으로 이상 발생 빈도 분석
```

👉 분야만 다를 뿐, 분석 방법은 거의 동일
