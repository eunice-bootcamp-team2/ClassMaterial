문제 1️⃣ 평균 기준 정상/이상 판단

관제 질문
> 지금 값은 평소 범위 안인가?

문제
최근 1분 센서 값이 아래와 같다.
```python
values = [98, 100, 101, 99, 100, 102]
current = 108
```

현재 값이 정상인지 이상인지 판단하라.

정답 코드
```python
import numpy as np

mean = np.mean(values)
std = np.std(values)

if current > mean + 2 * std:
    print("이상")
else:
    print("정상")
```

훈련되는 사고
> 정상 = 평균 근처  
> 이상 = 평균에서 많이 벗어남

문제 2️⃣ 변화량으로 위험 감지

관제 질문
> “값이 커진 게 문제인가, 빨리 커진 게 문제인가?”

문제
```python
values = [90, 92, 95, 100, 110]
```
마지막 증가가 위험한지 판단하라.

정답 코드
```python
delta = values[-1] - values[-2]

if delta >= 10:
    print("급격한 상승 → 위험")
```

훈련되는 사고
> 절대값보다 변화량

---
문제 3️⃣ 증가 속도(기울기) 판단

관제 질문
> 이 상승은 평소보다 빠른가?

문제
```python
values = [90, 92, 94, 96, 110]
```

정답 코드
```python
slope = (values[-1] - values[0]) / len(values)

if slope > 3:
    print("비정상 상승")
```

훈련되는 사고
> 속도 = 위험 신호

문제 4️⃣ 이동 평균으로 노이즈 제거

관제 질문
> “이 값이 진짜 위험인가, 순간 튄 값인가?”

문제
```python
values = [100, 101, 150, 102, 101]
```

정답 코드
```python
import numpy as np

rolling_mean = np.mean(values[-3:])

print("최근 평균:", rolling_mean)
```

훈련되는 사고
> 관제 AI는 즉시 반응 ❌ / 평균으로 판단 ⭕

문제 5️⃣ 센서 고장 의심 판단

관제 질문
> 이 센서, 고장 난 거 아닌가?

문제
```python
values = [100, 101, 102, 500, 501, 502]
```

정답 코드
```python
mean = np.mean(values[:-3])
std = np.std(values[:-3])

if values[-1] > mean + 5 * std:
    print("센서 고장 의심")
```

훈련되는 사고
> 물리적으로 불가능한 값 = 고장 가능성
