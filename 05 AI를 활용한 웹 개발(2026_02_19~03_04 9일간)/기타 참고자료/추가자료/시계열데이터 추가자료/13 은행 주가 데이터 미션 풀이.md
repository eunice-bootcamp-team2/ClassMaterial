문제 1

📌 거래량과 가격 변수(시가/종가/고가/저가)의 상관성 검정


① 결측치 확인 (기본 체크)
```python
df_hana1['거래량'].isnull().sum()
```

- 결과: `0`
- 👉 결측치 없음 → 바로 분석 가능

---

② 거래량 정규성 검정
```python
stats.normaltest(df_hana1['거래량'])
```

가설
- 귀무가설(H₀): 거래량은 정규분포를 따른다
- 대립가설(H₁): 정규분포가 아니다

결과
- p-value ≈ 1.04e-05 (< 0.05)

✅ 귀무가설 기각 → 정규성 ❌

---

③ 왜 Pearson이 아니라 Spearman인가?

|조건|선택|
|---|---|
|정규성 만족|Pearson|
|정규성 불만족|**Spearman**|

👉 거래량이 정규분포가 아니므로 **Spearman 상관계수 사용**

---

④ Spearman 상관계수 계산
```python
df_hana1[['거래량','시가','종가','저가','고가']]
.corr(method='spearman')['거래량']
```

결과 요약:

|변수|상관계수|
|---|---|
|시가|0.043|
|종가|0.023|
|저가|0.028|
|고가|0.073|

👉 상관계수 자체가 매우 작음

---

⑤ 상관성 유의성 검정 (p-value)
```python
for iin ['시가','종가','저가','고가']:
print(stats.spearmanr(df_hana1['거래량'], df_hana1[i]))
```

모든 결과:
- p-value > 0.05

✅ 귀무가설 채택
✅ 거래량과 가격 변수들은 통계적으로 유의한 상관관계 없음

---

✔ 문제 6 결론
> 거래량과 시가/종가/고가/저가 사이에는 통계적으로 유의미한 상관관계가 없다

문제 2

📌 25년도 2·3월 vs 4·5월 거래량 평균 차이 검정

---

① 비교 집단 생성
```python
cond1 = df_hana1['월'].isin([2,3])
cond2 = df_hana1['월'].isin([4,5])

df0203 = df_hana1.loc[cond1]
df0405 = df_hana1.loc[cond2]
```

- 집단 1: 2~3월
- 집단 2: 4~5월

---

② 각 집단 정규성 검정
```python
stats.normaltest(df0203['거래량'])
stats.normaltest(df0405['거래량'])
```

두 집단 모두:
- p-value < 0.05

❌ 정규성 만족하지 않음

---

③ 어떤 평균 비교 검정을 써야 하는가?

|조건|선택|
|---|---|
|정규성 만족|t-test|
|정규성 불만족|**비모수 검정**|

👉 Wilcoxon rank-sum (Mann–Whitney U 계열) 사용

---

④ Rank-sum 검정
```python
stats.ranksums(df0203['거래량'], df0405['거래량'])
```

가설
- H₀: 두 집단의 중앙값은 같다
- H₁: 두 집단의 중앙값은 다르다

결과
- p-value > 0.05

✅ 귀무가설 채택

    **시가 / 종가 / 저가 / 고가** 사이에

### ① 결측치 확인

```python
df_hana1['거래량'].isnull().sum()
```

- 결과: `0`
- 👉 결측치 없음 → 바로 분석 가능

---

### ② 거래량의 정규성 검정

```python
stats.normaltest(df_hana1['거래량'])
```

- **귀무가설(H0)**: 거래량은 정규분포를 따른다
- **대립가설(H1)**: 정규분포를 따르지 않는다

### ③ 스피어만 상관계수 계산

```python
df_hana1[['거래량','시가','종가','저가','고가']].corr(method='spearman')['거래량']
```

또는 개별 검정:

```python
for i in ['시가','종가','저가','고가']:
    print(stats.spearmanr(df_hana1['거래량'], df_hana1[i]))
```

📌 결과

- 모든 변수에서 **p-value > 0.05**

✅ **결론**

> 거래량과 시가/종가/저가/고가 사이에는
> 
> **통계적으로 유의한 상관관계가 없다**

## 7️⃣ 2025년 2·3월 vs 4·5월 거래량 평균 차이 검정

### 🎯 목적

- **시기별(월별) 거래량 차이가 존재하는지** 검정

---

### ① 그룹 분리

```python
cond1 = df_hana1['월'].isin([2,3])
cond2 = df_hana1['월'].isin([4,5])

df0203 = df_hana1.loc[cond1]
df0405 = df_hana1.loc[cond2]
```

---

### ② 각 그룹 정규성 검정

```python
stats.normaltest(df0203['거래량'])
stats.normaltest(df0405['거래량'])
```

📌 결과

- 두 그룹 모두 **p-value < 0.05**
- 👉 **정규성 만족 ❌**

---

### ③ 어떤 검정을 써야 할까?

|조건|선택|
|---|---|
|연속형 데이터|⭕|
|독립된 두 집단|⭕|
|정규성 불만족|⭕|

👉 **비모수 검정 필요**

✅ **Wilcoxon Rank-Sum Test (Mann–Whitney U)** 사용

---

### ④ Rank-Sum Test 수행

```python
stats.ranksums(df0203['거래량'], df0405['거래량'])
```

- **귀무가설(H0)**: 두 집단의 중앙값은 같다
- **대립가설(H1)**: 두 집단의 중앙값은 다르다

📌 결과

- p-value > 0.05

---

### ✅ 최종 결론

> 2025년 2·3월과 4·5월의 거래량 평균(중앙값)은 통계적으로 유의미한 차이가 없다
