- 회귀 기반 예측 맛보기

👉 정상성을 만들기 위한 전처리 훈련

🔹 8번 : 가장 단순한 기준선 (Naive)
- 아무 모델도 안 쓰면 어느 정도인가?

👉 모든 예측의 기준선

---
- rolling mean
- rolling std
- z-score 계산
- 임계치 경보 로직
- Sliding Window 사고 방식
- 최근 30초 데이터만 사용
- 최근 N개 평균 비교
- 상태 변화 감지
- Isolation Forest

- 센서 데이터에 강함
- 이상 탐지 대표 모델
-  Change Point Detection

⭐ 1단계 — Rolling 통계 기반 탐지 (가장 중요)

- 어떤 플랫폼에서도 사용 가능
- 모델 없이 구현 가능
- 계산 가벼움 → 실시간 처리 적합
- 디버깅 / 해석 쉬움
    

여기서 배우는 핵심 감각:
✅ 정상 상태의 평균 범위  
✅ 변동성 개념  
✅ 노이즈 vs 이상 구분

이게 안 잡히면 뒤에 ML도 의미 없어집니다.

---
⭐⭐ 2단계 — Sliding Window 사고 방식

실시간 센서 시스템 필수 개념입니다.

중요 이유:
센서 데이터는 이렇게 오지 않습니다:
`전체 CSV → 분석`
이렇게 옵니다:
`현재 시점 기준 최근 N초 데이터`

여기서 배우는 실무 감각:
✅ 실시간 처리 구조  
✅ Latency 이해  
✅ 메모리/성능 개념  
✅ 온라인 판단 로직

---
⭐⭐⭐ 3단계 — Z-score + 임계치 경보

관제 시스템의 가장 기본적인 경보 구조.

실무에서 매우 흔함:
- ±3σ 규칙
- Threshold Alert
- 간단하지만 강력
    
이걸 직접 구현하면:
👉 AI 시스템 동작 원리를 완전히 이해하게 됩니다.

---
⭐⭐⭐⭐ 4단계 — Isolation Forest (핵심 ML 모델)

이 단계가 중요한 이유:
✔ 라벨 없어도 학습 가능 ⭐⭐⭐⭐⭐  
✔ 센서 데이터에 매우 강함  
✔ 이상 탐지 대표 모델  
✔ 산업 현장에서 실제 사용 많음

특히 관제 시스템에서:
👉 지도학습보다 먼저 등장하는 모델

---
⭐⭐⭐⭐⭐ 5단계 — Change Point / 급변 탐지

이건 고급 탐지 영역입니다.

감지 대상:
- 상태 전이
- 고장 시작 시점
- 패턴 붕괴
- 드리프트
    
관제 시스템에서 매우 중요.
