---
1️⃣ 문제 정의 (가장 중요)

🎯 목표
> 시간 정보를 X로 사용하여 ‘종가’를 예측하는 회귀 모델 구성

입력 / 출력 정의
- X (설명 변수)
    - 연도
    - 월
    - 일
    - 요일
    - 거래량
- Y (타깃)
    - 종가

👉 이제 문제는 시계열 문제가 아니라 회귀 문제다.

---

2️⃣ 시간 파생 변수 생성
```python
df_hana['연도'] = df_hana['날짜_dt'].dt.year
df_hana['월'] = df_hana['날짜_dt'].dt.month
df_hana['일'] = df_hana['날짜_dt'].dt.day
df_hana['요일'] = df_hana['날짜_dt'].dt.day_name()
```

🔍 의미
- 시계열의 흐름을
    → 명시적인 숫자/범주 변수로 변환
    
- 머신러닝 모델이 이해 가능한 형태
    
---

3️⃣ X / Y 데이터 구성
```python
X = df_hana[['연도', '월', '일', '요일', '거래량']]
Y = df_hana['종가']
```

✔️ 요일은 문자형(범주형)
✔️ 나머지는 숫자형

---

4️⃣ Train / Test 분리
```python
from sklearn.model_selection import train_test_split

X_train, X_test, Y_train, Y_test = train_test_split(
    X, Y, test_size=0.3, random_state=1234
)
```

> 시계열 순서 기반 분할이 아니라
> 회귀 문제 기준 랜덤 분할을 사용

---

5️⃣ 전처리 + 모델 파이프라인 구성 (⭐ 핵심)

숫자형 처리
```python
pipe_num = make_pipeline(
    SimpleImputer(strategy='median')
)
```

문자형(요일) 처리
```python
pipe_cat = make_pipeline(
    SimpleImputer(strategy='most_frequent'),
    OneHotEncoder(handle_unknown='ignore')
)
```

ColumnTransformer
```python
preprocess = make_column_transformer(
    (pipe_num, ['연도','월','일','거래량']),
    (pipe_cat, ['요일'])
)
```

---

6️⃣ RandomForestRegressor 파이프라인
```python
model_pipe = make_pipeline(
    preprocess,
    RandomForestRegressor()
)
```

💡 왜 RandomForest?
- 비선형 관계 학습 가능
- 스케일링 필요 없음
- Feature Importance 제공

---

7️⃣ 하이퍼파라미터 튜닝 (GridSearchCV)
```python
param_grid = {
    'randomforestregressor__max_depth': [3,4,5],

```


8️⃣ 변수 중요도(Feature Importance) 확인

## 1 시간 파생 변수 생성 (Feature Engineering)

시계열 데이터를 그대로 쓰지 않고

👉 **시간을 의미 있는 숫자 변수로 분해**

```python
df_hana['연도'] = df_hana['날짜_dt'].dt.year
df_hana['월']   = df_hana['날짜_dt'].dt.month
df_hana['일']   = df_hana['날짜_dt'].dt.day
df_hana['요일'] = df_hana['날짜_dt'].dt.day_name()
```

### ✔ 왜 중요한가?

- 트리 계열 모델(RandomForest)은 **숫자/범주형 변수에 강함**
    
- “날짜 그 자체”보다
    
    → **요일 효과 / 월별 패턴 / 연도 트렌드**를 더 잘 학습

## 2 X / Y 데이터 구성

```python
X = df_hana[['연도','월','일','요일','거래량']]

```

- **X (입력 변수)**
    - 연도, 월, 일 → 시간 흐름
    - 요일 → 요일 효과
    - 거래량 → 시장 강도
- **Y (타깃)**
    - 종가 (연속형 값 → 회귀 문제)

## 4 전처리 + 모델 파이프라인 구성

### 📌 핵심 포인트

- 숫자형 / 문자형 컬럼 **분리 처리**
- 결측값 처리 + 인코딩 + 모델을 **한 번에 묶음**

```python
from sklearn.composeimport make_column_transformer
from sklearn.pipelineimport make_pipeline
from sklearn.imputeimport SimpleImputer
from sklearn.preprocessingimport OneHotEncoder
from sklearn.ensembleimport RandomForestRegressor
```

### 파이프라인 구조

```python
pipe_num = make_pipeline(SimpleImputer(strategy='median'))
pipe_cat = make_pipeline(
    SimpleImputer(strategy='most_frequent'),
    OneHotEncoder(handle_unknown='ignore')
)

preprocess = make_column_transformer(
    (pipe_num, ['연도','월','일','거래량']),
    (pipe_cat, ['요일'])
)

model_pipe = make_pipeline(
    preprocess,
    RandomForestRegressor()
)

model_pipe.fit(X_train, Y_train)
```

✔ 장점

- 전처리 + 학습 **실수 없이 자동 연결**
- 실무/과제에서 매우 중요한 패턴

---

## 5 하이퍼파라미터 튜닝 (GridSearchCV)

```python
from sklearn.model_selectionimport GridSearchCV

param_grid = {
'randomforestregressor__max_depth': [3,4,5],
'randomforestregressor__min_samples_split': [10,50],
'randomforestregressor__n_estimators': [200]
}

grid_model = GridSearchCV(
    model_pipe,
    param_grid=param_grid,
    cv=3,
    scoring='r2',
    n_jobs=-1
)

grid_model.fit(X_train, Y_train)
best_model = grid_model.best_estimator_
```

### ✔ 의미

- 여러 랜덤포레스트 설정 중
- **가장 R²가 좋은 모델 자동 선택**

## 7 모델 성능 평가

```python
from sklearn.metricsimport r2_score, mean_squared_error

Y_test_pred = best_model.predict(X_test)

print("R2 :", r2_score(Y_test, Y_test_pred))
print("MSE:", mean_squared_error(Y_test, Y_test_pred))
```

### 결과 해석 예시

- **R² ≈ 0.96**
    - 설명력 매우 높음
- **MSE 값**
    - 절대 오차 크기 판단용
