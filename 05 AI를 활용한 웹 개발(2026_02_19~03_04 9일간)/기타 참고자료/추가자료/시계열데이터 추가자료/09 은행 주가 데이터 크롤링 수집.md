## 1) 계절성 제거(Seasonal Decomposition) 정리

### 계절성 제거가 뭐냐?

시계열 데이터를 **추세(Trend) + 계절성(Seasonal) + 잔차(Residual)** 로 분해해서

- **계절성을 “파악”하거나**
- **계절성을 “제거”해서 정상성(Stationarity)에 가까워지게** 만드는 과정.

### 방법 2가지

### (1) Classical Decomposition (전통적 분해)

- **가법(Additive)**: `Y = Trend + Seasonal + Residual`
    - 변동폭이 **일정한 크기**로 움직일 때
    - 계절성 제거: `Y - Seasonal`
- **승법(Multiplicative)**: `Y = Trend × Seasonal × Residual`
    - 변동폭이 **데이터 수준에 비례**해서 커지거나 작아질 때(주가처럼)
    - 계절성 제거: `Y / Seasonal`

➡️ 수업에서는 **가법/승법 둘 다 해봤는데 ADF 테스트 결과 p-value가 0.05보다 커서 정상성 실패**

즉,

- 계절성이 “범인”이 아닐 수도 있고,
- 또는 전통적 분해로는 계절성을 제대로 잡아내기 어려울 수도 있음.

### (2) STL (Seasonal-Trend decomposition using Loess)

- **로컬 회귀(LOESS)** 기반이라 Classical보다 **유연하게 복잡한 패턴**을 잡음
- 특히 주가처럼 복잡한 패턴에 STL을 많이 고려

➡️ STL로 계절성을 빼도 **ADF p-value가 여전히 0.05 초과 → 정상성 실패**

즉 “계절성 제거만으로는 해결 안 됨” 결론.

## 2) 차분(Differencing) 정리

### 차분이 뭐냐?

**현재 값 − 이전 값**

- 1차 차분: `diff(1)`
- 2차 차분: `diff(2)` (1차 차분 결과를 한 번 더 차분)

### 차분의 효과

- **추세 제거**
- 변동성을 더 일정하게 만들어서 **정상성 달성에 매우 자주 성공**

### 실습 흐름

1. `DF2['시가'].diff()`로 **1차 차분** → 첫 행은 이전값이 없어 **결측치(NaN)** 발생
2. 시각화하면 평균이 0 근처로 가고 패턴이 안정적으로 보임
3. ADF 테스트는 **결측치 제거 후** 수행
4. 결과: **p-value < 0.05 → 정상성 만족(귀무가설 기각)**

✅ 핵심 포인트

- 이제 “시가 자체”를 예측하는 게 아니라
    
    **“차분값”을 예측**하고,
    
- 예측된 차분을 마지막 시점 값에 **누적해서 원래 시가를 복원**하는 방식으로 감.

## 3) Darts로 나이브(Naive) 모델 예측 + 평가 정리

### 목적

정상성이 확보된 **차분값(시가_diff)** 을 가지고

Darts 라이브러리로 **가장 단순한 기준 모델(나이브)** 을 만들어 예측/시각화/평가까지 경험.

### (1) 라이브러리 설치 주의

- darts 설치 시 OS에 따라 빌드 문제 발생 가능
- Windows면 C++ 빌드 도구(Visual Studio Build Tools 등) 필요할 수 있음

### (2) Darts는 데이터 구조 변환이 필요

Pandas DataFrame → Darts TimeSeries 구조로 변환해야 함.

- `TimeSeries.from_dataframe(df, time_col, value_cols)`
    
- 주가 데이터는 주말/공휴일로 **날짜가 비는 구간**이 있어서 변환 중 에러 가능
    
    → `fill_missing_dates=True, freq="D"`로 **없는 날짜를 채움**
    
- 값(y)의 결측치는 `fillna_value=True` 같은 방식으로 채울 수 있음(기본은 단순대치)
    

### (3) NaiveSeasonal 모델 개념

- **k** = “몇 일 전 값을 가져와서 다음 값을 예측할지” (주기처럼 쓰임)
    
- `k=1`이면: **바로 전날 값**을 계속 미래 예측값으로 사용
    
    → 미래 30일 예측하면 값이 똑같이 반복되는 이유가 이거임
    
- `k=10`이면: **10일 전 패턴**을 반복해서 예측 (주기성이 있다고 가정)
    

### (4) 예측값 시각화

- 예측 결과(TimeSeries)를 다시 DataFrame으로 바꾸고(`pd_dataframe()`),
- 실측 DF2와 concat해서
- 라벨(실측/예측)을 붙여 plotly로 한 번에 표시

### (5) 평가 방식(데이터마이닝 방식)

- 시계열은 랜덤 셔플 X
- 앞 80% = train, 뒤 20% = test 로 **순서 유지 split**
- train으로 fit → test 길이만큼 predict
- MSE / RMSE로 평가

➡️ 나이브는 너무 단순해서 RMSE가 크게 나와도 자연스러운 결과.

(“기준선(baseline)” 모델로 의미가 있음)
