데이터 포맷 수정이란?
	데이터를 분석하기 전에 형식을 통일하고, 다루기 쉬운 형태로 바꾸는 작업으로,
	현실 세계에서 모은 데이터는 다양하고 복잡한 형식으로 되어 있어서,  
→ 데이터 분석/모델링 전에 꼭 포맷을 정리해야 합니다!

데이터 포맷 수정 예시:
```python
import pandas as pd

df = pd.read_csv("csv_files/combined_customers.csv")
# DataFrame은 엑셀 표처럼 생긴 2차원 표 형식의 데이터 구조입니다.

df['age'].fillna(0, inplace=True)
df['age'] = df['age'].astype('int')
print(df)
```
---
`df[선택할 데이터]` 표현법 정리:

판다스에서 열을 지정할 때는 `df['열이름']` 형식을 써요.
`df[선택할 데이터]` 즉 판다스의 문법입니다.

- `df['column_name']`: 특정 열(컬럼)을 선택
- `df[['col1', 'col2']]`: 여러 열을 리스트로 선택
- `df[0:3]`: 슬라이싱으로 행(row)을 선택 (0~2행)
- `df[df['age'] > 30]`: 조건에 맞는 행(row)만 필터링
- `df.loc[1]`: 라벨 기반 인덱싱 (인덱스가 1인 행)
- `df.iloc[1]`: 순서 기반 인덱싱 (1번째 행)
---
결측치 채우기 + 데이터 타입 변경
```python
df['age'].fillna(0, inplace=True)  # age가 비어있으면 0으로 채움
df['age'] = df['age'].astype('int')  # age를 정수(int) 타입으로 바꿈
```

`df['age'].fillna(0, inplace=True)`
- `df['age']`: 나이(age) 열을 가져옵니다.
- `.fillna(0)`: `age`에 비어 있는 값(NaN)이 있다면 0으로 채웁니다. 
  예: 결측치 → 0살 처리
- `inplace=True`: 원본 데이터프레임(df)을 직접 수정합니다.

쉽게 말하면 나이 정보가 비어있는 사람은 임시로 0살이라고 적어두는 거예요.
왜 이렇게 하냐면?
- 결측치(NaN)가 있는 상태로는 평균 계산, 정렬 등이 에러를 내거나 무시될 수 있기 때문입니다.
- 0살은 실제 값이라기보다 "비어 있음"을 표시하는 기호 값처럼 사용하는 거예요.

`df['age'] = df['age'].astype('int')`
- `astype('int')`: 나이 열의 자료형을 `정수형(int)`으로 바꿉니다.
- 원래는 나이가 비어 있었기 때문에 `float` 형식이었을 수도 있어요.
- `df['age'] = df['age'].astype('int')`는 변수 대입으로 일반 변수와는 다르게 열(column)에 새로운 값을 할당하는 방식 입니다.

쉽게 말하면 소수점(예: 30.0)으로 되어 있는 나이를 정수(30)으로 바꾸는 거예요.
왜 이렇게 하냐면?
- 나이는 일반적으로 정수로 표현하니까요.
- 정수로 바꾸면 이후에 조건 검색(예: `df[df['age'] > 20]`)이나 통계 처리도 더 간편합니다.
- 비어 있는 데이터(NaN)가 들어오면 그 열 전체의 데이터 타입에 따라 자동으로 처리되는데 보통은 소수점(float)형식이 됩니다.

`print(df)`
- 바뀐 `age` 값을 포함한 전체 DataFrame을 출력합니다

날짜/시간 다루기
`join_date` 컬럼을 날짜/시간 단위로 분해해서 보여줌
```python
df['join_date'] = pd.to_datetime(df['join_date'])  
# 문자열을 날짜로 바꿈

df["year"] = df["join_date"].dt.year
df["month"] = df["join_date"].dt.month
df["day"] = df["join_date"].dt.day
df["hour"] = df["join_date"].dt.hour
df["minute"] = df["join_date"].dt.minute
print(df)
```

- `to_datetime()`은 판다스(pandas)의 함수이고, 날짜·시간 문자열을 진짜 날짜형식(datetime)으로 변환해주는 함수입니다.
- `.dt.year` 등 → 날짜에서 연도, 월, 일, 시, 분을 각각 뽑아냅니다.
- 이렇게 분리하면 월별 분석, 시간대별 분석 등에 활용할 수 있어요.

```python
import pandas as pd

# 1. CSV 파일 불러오기
df = pd.read_csv("csv_files/combined_orders.csv")

# ------------------------------------------------------------
print("[1] 원본 데이터 미리보기")
print("-" * 100)
print(df.head())

# 2. 결측치 처리: order_amount 결측치 → 0으로 채우기
df['order_amount'].fillna(0, inplace=True)

# 3. order_amount 열을 정수형으로 변환
df['order_amount'] = df['order_amount'].astype('int')

# 4. order_date 열을 datetime 형식으로 변환
df['order_date'] = pd.to_datetime(df['order_date'])

# 5. 날짜 구성 요소 추출
df['year'] = df['order_date'].dt.year
df['month'] = df['order_date'].dt.month
df['day'] = df['order_date'].dt.day
df['hour'] = df['order_date'].dt.hour
df['minute'] = df['order_date'].dt.minute

# ------------------------------------------------------------
print()
print("[2] 가공된 데이터 미리보기")
print("-" * 100)
print(df.head())

# 6. 결과 출력
print()
print("[3] 가공된 주문 데이터:")
print("-" * 100)
print(df.head())  # 상위 5개 행만 출력

# ------------------------------------------------------------
print()
print("[4] 분석 결과 요약")
print("-" * 100)

# 가장 많은 주문이 들어온 연도
most_orders_year = df['year'].value_counts().idxmax()
print(f"\n 가장 주문이 많았던 연도: {most_orders_year}년")

# 주문 금액 평균
avg_order_amount = df['order_amount'].mean()
print(f"주문 금액 평균: {avg_order_amount:.2f} 원")
```
