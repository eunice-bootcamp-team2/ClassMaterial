현재 어느 폴더에 있던 상관없이 명령어를 입력한다.
```bash
cd ~  # 홈디렉토리 이동
```

가상환경 안에 들어가 있을 경우:
```bash
(venv)  # 가상환경안에 있다.

# 가상환경 나오기
deactivate

# 가상환경 탈피경로 (venv)가 사라졌다.
youjung@DESKTOP-PJCRMMU:~$
```

폴더만들기:
```bash
mkdir dd  # dd라는 폴더를 만들겠다.
# 그러면 아무일도 일어나지 않는다

# 만든 폴더로 이동
cd dd
# youjung@DESKTOP-PJCRMMU:~/dd$
```

지금 생성한 폴더 안으로 이동하기
```bash
code -r . # 생성한 폴더로 들어가기
```

파일이 내가 생성한 폴더안에 정말 있는지 확인하는 명령어
```bash

ls -a # 숨겨진 목록까지 모두 보기
```
