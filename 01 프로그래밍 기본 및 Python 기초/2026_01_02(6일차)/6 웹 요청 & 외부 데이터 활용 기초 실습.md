### 🔹 1. 웹 요청·응답 기초 개념

```
우리는 브라우저(클라이언트)로
특정 주소(URL)을 입력하여
서버에게 어떤 기능(엔드포인트: API의 구체적인 기능 주소)을 요청(Request)하고
서버는 그 결과(Response)를 보내줍니다.
```

#### 1-1. Client / Server 개념

- **클라이언트(Client)**
    → 요청을 보내는 쪽
    → 예: 크롬 브라우저, 모바일 앱, 파이썬 스크립트(내 코드)
    
- **서버(Server)**
    → 요청을 받고, 처리한 뒤 응답을 돌려주는 쪽
    → 예: 구글 서버, 네이버 서버, 내가 나중에 만들 Django/FastAPI 서버
    
**한 줄 요약**

> “클라이언트가 서버에게 ‘이 페이지/데이터 좀 줘!’라고 요청하고,
> 서버가 ‘여기 있어!’ 하고 응답을 보내는 구조”

---
#### 1-2. 브라우저와 HTTP

- **브라우저**(크롬, 엣지, 사파리…) = 사람이 쓰는 클라이언트 도구
- 브라우저는 **HTTP 프로토콜**을 사용해서 서버와 통신합니다.

HTTP = HyperText Transfer Protocol
→ “웹에서 문서/데이터를 주고받는 약속(규칙)”

대표적인 HTTP 메서드:
- `GET` : “이 URL의 데이터를 달라”
- `POST` : “이 URL에 이런 데이터를 보낼게 (회원가입, 로그인, 글쓰기 등)”

| --- | ------------------------ | -------------------------------------- | -------------------------------------------------- |
| 01  | Scheme (스킴)              | 웹 주소의 시작 부분으로 이게 어떤 방식으로 연결할지 정해줘요.    | `http://`, `https://` ← 보안 연결 여부                   |

| 06  | Anchor <br>(앵커, 해시)      | 웹페이지 안의 특정 위치로 바로 이동할 때 써요.            | `#section1`, `#bottom`, `#title`                   |
그중 05번에 해당하는 Query Parameters
쿼리 파라미터란? 웹 주소(URL)에 추가 정보를 넣는 방식으로 주소 끝에 `?키=값` 형식으로 붙습니다. 
```
?key1=value1&key2=value2
```

2️⃣ QueryString (쿼리 파라미터)란?
> QueryString은 **URL 뒤에 붙는 추가 정보**입니다.  
> 서버에게 “검색 조건”이나 “옵션”을 전달할 때 사용합니다.

URL 뒤에 `?`로 붙는 **추가 정보**
```
?키=값&키2=값2

?key=value&key2=value2
```

예제:
```
https://google.com/search?q=python&page=2
```

|요소|의미|
|---|---|
|q=python|검색어|
|page=2|페이지 번호|

👉 즉, QueryString은 서버에게 “이 조건으로 처리해줘”라고 말하는 방식입니다.

### 확장 실습 (Pagination 느낌만 배워보기)

데이터 목록이 있다고 가정 👇
```python
items = ["사과", "바나나", "딸기", "포도", "수박"]

def get_items(skip=0, limit=2):
    return items[skip: skip + limit] # [0:2]

print(get_items(skip=1, limit=3))  #[1:3]
# ['바나나', '딸기', '포도']
```

👉 실제 서비스에서는 URL로 받는 값
```bash
?page=1&limit=3
```

을 처리해서 필요한 만큼만 가져오는 구조가 된다!

items 리스트의 실제 구조 (인덱스 기준)
```python
items = ["사과", "바나나", "딸기", "포도", "수박"]
```

| 인덱스 | 값   |
| --- | --- |
| 0   | 사과  |
| 1   | 바나나 |
| 2   | 딸기  |
| 3   | 포도  |
| 4   | 수박  |
지금 호출한 코드
```python
print(get_items(skip=1, limit=3))
```

함수 내부에서는 이렇게 계산됩니다:
```python
items[1 : 1 + 3]
items[1 : 4]
```

Python 슬라이싱의 **가장 중요한 규칙**
```python
list[start : end]
```
이 뜻은:

> **start 인덱스부터 시작해서  
> end 인덱스 "바로 전까지" 전부 가져온다**

즉,
```python
items[1:4]
```

은 아래 인덱스를 가져옵니다:

| 포함 여부 | 인덱스 | 값   |
| ----- | --- | --- |
| ✅ 포함  | 1   | 바나나 |
| ✅ 포함  | 2   | 딸기  |
| ✅ 포함  | 3   | 포도  |
| ❌ 제외  | 4   | 수박  |
그래서 결과가:
```python
["바나나", "딸기", "포도"]
```

지금 단계에서 이것만 이해하면 성공

✔️ `?page=1&limit=3` 는  
👉 문자열이다

✔️ 서버는 그 문자열을  
👉 파이썬 코드로 분해한다

✔️ pagination은  
👉 리스트 슬라이싱으로 구현된다

#### 1-4. HTTP Status Code(상태 코드)

서버가 응답을 줄 때, **결과가 어땠는지 숫자로 알려주는 코드**입니다.
###### ✔️ 상태 코드 전체 분류표
| 범위      | 의미               | 예시                               |
| ------- | ---------------- | -------------------------------- |
| **1xx** | 요청은 받았고 처리 중     | _거의 볼 일 없음_                      |
| **2xx** | 요청 성공            | **200 OK** 👍                    |
| **3xx** | 추가 행동 필요 (리다이렉트) | **301**, **302**                 |
| **4xx** | 클라이언트(사용자) 실수    | **404 Not Found**400 Bad Request |
| **5xx** | 서버(개발자) 문제       | **500 Internal Server Error**    |
###### ✔️ 자주 보는 대표 상태코드 

| 코드                            | 의미               | 초보자 이해용 예           |
| ----------------------------- | ---------------- | ------------------- |
| **200 OK**                    | 성공               | “응! 여기 데이터 있어!”     |
| **201 Created**               | 새 데이터 생성 성공      | 회원가입 완료, 글쓰기 성공     |
| **204 No Content**            | 성공했는데 응답 본문 없음   | 삭제 완료 시(내용 없이 성공)   |
| **301 / 302 Redirect**        | 주소 바뀜 → 다른 데로 이동 | 구 주소로 접속하면 새 주소로 이동 |
| **400 Bad Request**           | 요청 자체가 잘못됨       | 데이터 형식 오류           |
| **401 Unauthorized**          | 로그인 안 됨          | 인증 토큰 없음            |
| **403 Forbidden**             | 권한 부족            | 관리자 아니면 못 봄         |
| **404 Not Found**             | 페이지 없음           | 주소 오타               |
| **500 Internal Server Error** | 서버 터짐(개발자 잘못)    | 버그, 예외 처리 안 됨       |

### 실습 예제 (Python + requests)

main.py 코드 작성
```python
import requests

urls = [
    "https://google.com",                # 200 OK
    "https://google.com/nonexist",       # 404 Not Found
    "https://httpbin.org/status/500",    # 500 Internal Server Error
    "https://httpbin.org/status/302"     # 302 Redirect
]

for url in urls:
    response = requests.get(url)
    print(f"URL: {url}")
    print("Status Code:", response.status_code)

    if response.status_code == 200:
        print("→ 정상적으로 데이터를 받았습니다! 😊")
    elif response.status_code == 404:
        print("→ 주소가 잘못되었나봐요! 😢 페이지가 없어요.")
    elif response.status_code == 500:
        print("→ 서버가 아파요! 개발자가 고쳐야 해요 ⚠️")
    elif 300 <= response.status_code < 400:
        print("→ 다른 페이지로 이동시키고 있어요 🔁")
    
    print("-" * 50)
```

### 🔹 JSON 응답 다루기

JSON이란?
백엔드/프론트/모바일이 서로 대화할 때 거의 전부 JSON으로 이야기합니다.
	**JSON(JavaScript Object Notation)**  
	→ “키-값”으로 이루어진 데이터를 문자열 형태로 주고받는 형식

사실 **파이썬의 dict + list**랑 거의 똑같이 생겼어요.
```json
{
  "id": 1,
  "title": "파이썬 기초 JSON 연습",
  "completed": false,
  "tags": ["python", "json", "api"],
  "author": {
    "name": "Eunice",
    "age": 30
  }
}
```
- `"id"` → key (이름표)
- `1` → value (값)
- `"title"` → 할 일 제목
- `"completed"` → 끝났는지 여부 (true/false)
- `{ }` : “객체(오브젝트)”
- `"키": 값` : 하나의 정보
- `[]` : 리스트(여러 개 묶음)

|JSON 타입|예시|파이썬에서 대응|
|---|---|---|
|Object|`{ "id": 1 }`|`dict`|
|Array|`[1, 2, 3]`|`list`|
|String|`"hello"`|`str`|
|Number|`123`, `3.14`|`int`, `float`|
|Boolean|`true`, `false`|`True`, `False`|
|Null|`null`|`None`|

왜 JSON이 중요할까?

요즘 앱/웹 구조를 아주 단순하게 보면:
- **백엔드 서버 (Django, DRF, FastAPI 등)**  
    → 데이터를 JSON으로 만들어서 보내줌
    
- **프론트엔드 (React/Vue, 모바일 앱, JS)**  
    → 이 JSON을 받아서 화면에 뿌려줌
    
즉,
- **서버 ↔ 프론트**
- **서버 ↔ 서버**
- **파이썬 ↔ 다른 언어**
    
서로 말을 주고받을 때  
**공통 언어 = JSON** 인 경우가 대부분이에요.

###### JSON vs HTML vs CSV 간단 비교
|형식|생김새 예시|주 용도|초보자 감각용 한 줄|
|---|---|---|---|
|**HTML**|`<h1>제목</h1>`|웹 페이지 화면|“화면 모양을 만드는 언어”|
|**CSV**|`1,파이썬 공부,false`|엑셀·테이블형 데이터|“엑셀 표를 문자열로 저장한 것”|
|**JSON**|`{"id":1,"title":"파이썬 공부","completed":false}`|API, 서버-클라이언트 통신|“데이터 구조 자체를 표현하는 형식”|
- 브라우저는 **HTML**을 받아서 예쁘게 그려줍니다.
- 데이터 분석/엑셀은 **CSV**를 좋아합니다.
- **프로그램끼리 통신(특히 API)** 은 대부분 **JSON**을 씁니다.
    
우리의 목표는:
> “파이썬 코드로 JSON을 받아서  
> 파이썬 dict/list처럼 **바로 다루는 방법**을 익히는 것”

```python
# requests 라이브러리 불러오기
# → 파이썬으로 웹 서버에 HTTP 요청을 보내기 위한 도구

# ----------------------------------------
```

📝 문제 1 — 외부 API에서 특정 단어가 포함된 제목만 필터링하기

API 주소
```
https://jsonplaceholder.typicode.com/posts
```
이 API는 여러 사용자가 작성한 게시글 목록을 JSON 형식으로 반환합니다.

🎯 수행할 작업
1. userId가 1인 게시글만 API로 조회합니다.  
    (힌트: `userId=1` 조건을 함께 전달)
    
2. 서버로부터 받은 **게시글 목록(JSON)** 을  
    파이썬에서 사용할 수 있도록 변환합니다.
    
3. 게시글 중에서  
    **`title`(제목)에 `"qui"` 라는 문자열이 포함된 게시글만 찾아서 출력**합니다.

📋 출력 조건
- 출력 형식은 아래와 같이 합니다.
```bash
[id=게시글ID] 게시글 제목
```
조건에 맞는 게시글이 여러 개라면 모두 한 줄씩 출력합니다.

✨ 정답 코드 : `mission1_filter_title.py`
```python
# requests 라이브러리 불러오기
# → 파이썬 코드로 웹 서버(API)에 요청을 보내기 위해 필요
import requests


# -------------------------------
# 1) API 호출 (userId=1 조건)
# -------------------------------

# 요청할 API 주소
# jsonplaceholder는 연습용(가짜) API 서버
# /posts 는 게시글 목록을 의미
url = "https://jsonplaceholder.typicode.com/posts"


# 쿼리 파라미터(query parameter)
# userId=1 인 게시글만 달라고 서버에 요청하기 위한 조건
# 브라우저 주소로 치면 ?userId=1 과 같은 의미
params = {"userId": 1}


# GET 요청 보내기
# → 서버에 "userId가 1인 게시글 목록을 주세요" 라고 요청
response = requests.get(url, params=params)


# -------------------------------
# 2) JSON → 파이썬 데이터 변환
# -------------------------------

# 서버가 JSON 형식으로 응답한 데이터를
# 파이썬에서 사용할 수 있도록 변환
# 결과는 여러 개의 게시글이 들어 있는 리스트(list)
posts = response.json()


# -------------------------------
# 3) 조건에 맞는 제목만 출력
# -------------------------------

# 출력용 제목
print("=== 'qui'가 포함된 제목 목록 ===")


# posts 리스트에 들어 있는 게시글을 하나씩 꺼내서 반복
for post in posts:
    # post는 하나의 게시글이며, 딕셔너리(dict) 형태
    # post["title"] 은 게시글의 제목
    # "qui" in post["title"] 은
    # 제목 안에 'qui'라는 문자열이 포함되어 있는지 확인
    if "qui" in post["title"]:
        # 조건을 만족하는 경우에만 출력
        # post['id']    → 게시글 번호
        # post['title'] → 게시글 제목
        print(f"[id={post['id']}] {post['title']}")
```

📝 문제 2 — 외부 API 응답을 JSON 파일로 저장하기
	외부 API 서버에서 JSON 데이터를 받아서, 그 데이터를 로컬 파일(JSON 파일)로 저장하는 과정을 연습

API 응답 → 파이썬 객체 → JSON 파일 저장

API 주소:
```
https://jsonplaceholder.typicode.com/posts/1
```
	이 주소는 id가 1인 게시글 하나를 JSON 형식으로 반환합니다.

🎯 수행할 작업
1. 위 API 주소로 요청을 보내  
    id=1인 게시글 데이터를 가져옵니다.
    
2. 서버에서 받은 JSON 응답을 파이썬 데이터(dict) 로 변환합니다.
    
3. 변환된 데이터를  
    `post1.json` 이라는 파일로 저장합니다.

📋 저장 조건
- 파일 이름: `post1.json`
- 파일 형식: JSON
- 한글이 깨지지 않도록 저장
- 들여쓰기(indent)를 적용하여 **사람이 읽기 쉬운 형태**로 저장

✨ 정답 코드 : `mission2_save_json.py`
```python
# json과 requests 라이브러리 불러오기
# json     → 파이썬 데이터를 JSON 파일로 저장하거나 불러올 때 사용
# requests → 파이썬으로 웹 서버(API)에 요청을 보내기 위한 도구
import json
import requests


# -------------------------------
# 1) API 호출
# -------------------------------

# 요청할 API 주소
# jsonplaceholder는 연습용(가짜) API 서버
# /posts/1 은 id가 1인 게시글 하나를 의미
url = "https://jsonplaceholder.typicode.com/posts/1"


# GET 요청 보내기
# → 서버에 "id가 1인 게시글 데이터를 주세요" 라고 요청
response = requests.get(url)


# -------------------------------
# 2) JSON → 파이썬 데이터 변환
# -------------------------------

# 서버가 JSON 형식으로 응답한 데이터를
# 파이썬에서 사용할 수 있도록 변환
# 결과는 하나의 게시글 정보가 담긴 딕셔너리(dict)
post = response.json()


# -------------------------------
# 3) JSON 파일로 저장
# -------------------------------

# post1.json 파일을 "쓰기(w)" 모드로 열기
# encoding="utf-8" → 한글이 깨지지 않도록 설정
# with 문을 사용하면 파일을 자동으로 닫아줌
with open("post1.json", "w", encoding="utf-8") as f:
    
    # json.dump()
    # → 파이썬 딕셔너리(post)를 JSON 형식으로 파일에 저장
    # ensure_ascii=False → 한글을 유니코드(\uXXXX)로 바꾸지 않음
    # indent=2 → 들여쓰기를 적용해 사람이 읽기 쉽게 저장
    json.dump(post, f, ensure_ascii=False, indent=2)


# 파일 저장이 끝났음을 알려주는 메시지 출력
print("🎉 post1.json 파일 저장 완료!")
```

📂 실행 후 생성되는 파일 : `post1.json`

```json
  "id": 1,
  "title": "sunt aut facere repellat provident occaecati excepturi optio reprehenderit",
  "body": "quia et suscipit..."

```

4️⃣ 책 목록 전체 제목 가져오기

이번에는 첫 번째만 말고,

파일명: `cgv_movie_list.py`
```python
import requests
from bs4 import BeautifulSoup

url = "https://books.toscrape.com/"
resp = requests.get(url)
resp.raise_for_status()
soup = BeautifulSoup(resp.text, "lxml")

# 여러 개 선택: select()
books = soup.select("article.product_pod")

print("📝 현재 책 목록")
print("=" * 30)

for i, book in enumerate(books, start=1):
    # 각 책 카드 안의 h3 > a 태그
    title_tag = book.select_one("h3 a")
    if title_tag:
        title = title_tag["title"].strip()  # a 태그의 title 속성
        print(f"{i}. {title}")
```

핵심 포인트

- `soup.select("...")`
    - 여러 개의 요소를 **리스트**로 가져옴
    - 여기서는 책 하나가 `article.product_pod` 이므로,  
        책 리스트 전체가 리스트로 들어옴
        
- `for i, book in enumerate(books, start=1):`
    - `enumerate`는 (번호, 값)을 동시에 꺼내주는 도우미
    - `start=1` 로 해서 번호를 1부터 시작하게 함
        
- `title_tag["title"].strip()`
    - Books to Scrape에서는  
        `<a title="책 제목">` 속성 안에 제목이 들어있어서  
        `["title"]` 로 꺼내고, `.strip()` 으로 공백 제거

```python
from bs4 import BeautifulSoup

def fetch_news():
    """Hacker News 메인 페이지에서 뉴스 a 태그 목록을 가져오는 함수"""

        title = a.text.strip()
        href = a["href"]

        # 키워드 검색 (대소문자 구분 없이)
        if keyword.lower() in title.lower():
```

### 4단계 (선택) — 검색 결과를 파일로 저장하기
```python
import requests
from bs4 import BeautifulSoup

def fetch_news():
    url = "https://news.ycombinator.com/"
    resp = requests.get(url)
    resp.raise_for_status()
    soup = BeautifulSoup(resp.text, "html.parser")
    return soup.select("span.titleline a")

def main():
    print("📰 Hacker News 뉴스 검색 프로그램 (파일 저장 포함)")
    keyword = input("검색할 키워드를 입력하세요: ").strip()

    links = fetch_news()
    results = []

    for a in links:
        title = a.text.strip()
        href = a["href"]

        if keyword.lower() in title.lower():
            results.append(f"{title} ({href})")

    # 화면 출력
    print()
    print(f"🔎 '{keyword}' 검색 결과")
    print("=" * 40)

    if not results:
        print("검색 결과가 없습니다.")
    else:
        for i, line in enumerate(results, start=1):
            print(f"{i}. {line}")

        # 파일로 저장
        filename = f"hn_search_{keyword}.txt"
        with open(filename, "w", encoding="utf-8") as f:
            for line in results:
                f.write(line + "\n")

        print()
        print(f"✅ 검색 결과를 파일로 저장했습니다: {filename}")

if __name__ == "__main__":
    main()
```

### 🔹 디버깅 방법 + 코드 공유

#### 디버깅이란? 
	디버깅은 프로그램이 왜 안 되는지 찾아내고 고치는 과정이다. 에러는 실패가 아니라 성장의 기회

디버깅이 중요한 이유
- 실제 개발은 80%가 문제 해결(디버깅)
- 버그를 해결할수록 코드 이해도와 실력이 급상승
- 에러 메시지를 읽는 능력이 곧 개발자 언어 이해 능력

#### 코드 공유(Code Sharing)란?
	코드 공유는 **서로 도우며 더 좋은 코드를 만들기 위한 소통 방식**이다.

코드 공유가 필요한 이유
- 개발은 **혼자 하지 않는다** → 협업 필수!
- 다른 사람에게 도움을 **정확하게 요청할 수 있다**
- 버그 발생 시, 함께 디버깅이 가능하다

|키워드|설명|
|---|---|
|디버깅(Debugging)|코드 속 오류(버그)를 찾고 고치는 과정|
|예외(Exception)|프로그램 실행 중에 발생하는 “문제 상황” (에러)|
|`try / except`|에러가 나도 프로그램이 죽지 않게 “잡는” 문법|
|HTTP 상태 코드|200, 404, 500 등 요청 결과를 숫자로 알려줌|
|JSON `KeyError`|딕셔너리에서 없는 키를 꺼내려고 할 때 나는 에러|

목표:
	“에러가 나도 겁먹지 말고, 메시지를 읽고, `try/except`로 감싸고, 상태코드와 JSON 키를 확인하는 습관 가지기”

### 3. 예제 2 — `try / except`로 에러를 잡아보기

이번엔 같은 상황이지만, **프로그램이 죽지 않게** `try/except`를 씌워 봅니다.

파일: `debug_2_try_except.py`
```python
# debug_2_try_except.py

import requests

url = "<https://jsonplaceholder.typicode.come/posts/1>"  # 여전히 잘못된 URL

print("요청 보내는 중...")

try:
    response = requests.get(url, timeout=5)  # timeout도 같이 줘봄
    print("요청 성공!")
    print("상태 코드:", response.status_code)
except requests.exceptions.RequestException as e:
    # requests에서 나는 모든 에러의 부모 클래스: RequestException
    print("❗ 요청 중 오류가 발생했습니다.")
    print("에러 내용:", e)

print("프로그램이 여기까지는 정상적으로 계속 실행됩니다.")
```

### 6. 예제 5 — try/except + 상태코드 + JSON KeyError까지 한 번에

이제 **하나의 파일**에서
- HTTP 요청
- 예외 처리
- 상태 코드 체크
- JSON 파싱
- 키 확인

까지 종합적으로 연습해봅니다.

파일: `debug_5_final_example.py`
```python
# debug_5_final_example.py

import requests

def fetch_post(post_id: int) -> dict | None:
    """post_id에 해당하는 글을 JSON으로 가져온다. 실패하면 None 반환."""
    url = f"<https://jsonplaceholder.typicode.com/posts/{post_id}>"
    print(f"👉 요청 URL: {url}")

    try:
        response = requests.get(url, timeout=5)
    except requests.exceptions.RequestException as e:
        print("❗ 네트워크 오류가 발생했습니다.")
        print("에러 내용:", e)
        return None

    print("응답 상태 코드:", response.status_code)

    if response.status_code != 200:
        print("⚠️ 200 OK가 아니라서 JSON을 파싱하지 않습니다.")
        return None

    try:
        data = response.json()
    except ValueError as e:
        print("❗ JSON 파싱 중 오류 발생:", e)
        return None

    return data

def print_post_title_and_body(post_data: dict) -> None:
    """JSON 데이터에서 title과 body를 안전하게 출력."""
    # title
    if "title" in post_data:
        print("제목(title):", post_data["title"])
    else:
        print("⚠️ 'title' 키가 없습니다.")

    # body
    body = post_data.get("body")
    if body is None:
        print("⚠️ 'body' 키가 없거나 값이 없습니다.")
    else:
        print("\\n내용(body):")
        print(body)

def main():
    print("📌 JSONPlaceholder 글 조회 디버깅 예제")
    try:
        post_id = int(input("조회할 글 번호를 입력하세요 (예: 1): ").strip())
    except ValueError:
        print("❗ 숫자를 입력해주세요.")
        return

    post_data = fetch_post(post_id)

    if post_data is None:
        print("데이터를 가져오지 못했습니다. 프로그램을 종료합니다.")
        return

    print("\\n✅ 가져온 데이터:")
    print(post_data)

    print("\\n📝 제목과 내용만 출력:")
    print_post_title_and_body(post_data)

if __name__ == "__main__":
    main()
```
