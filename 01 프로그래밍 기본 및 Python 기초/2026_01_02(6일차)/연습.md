### 🔹 HTML 파싱 라이브러리 — BeautifulSoup 기초 (연습 사이트 버전)

> 브라우저 대신 파이썬이 웹페이지를 가져오고, 그 HTML에서 **원하는 부분만 골라서**(파싱) 뽑아올 수 있다.

정의:
- **requests**
    → “웹사이트야, 이 주소 페이지 좀 보내줘” 하고 **요청**을 보내는 라이브러리
    
- **BeautifulSoup**
    → 받은 HTML 문자열을 예쁘게 잘라서,
    `<title>`, `<div class="quote">`, `<span class="text">` 같은 **태그 단위로 찾기 쉽게 만들어주는 도구**
    

### 목표:

|학습 목표|설명|
|---|---|
|requests로 웹페이지 가져오기|브라우저 대신 파이썬이 HTML 다운로드|
|BeautifulSoup으로 HTML 분석|태그 구조를 이해하고 원하는 부분 찾기|
|텍스트만 뽑아오기|`.text` / `.strip()` 사용|
|리스트 반복하여 여러 데이터 뽑기|`for` 반복문 + `select()` 결과 처리|

> 결론:
> HTML 태그 구조만 보고도 **“여기 있는 데이터만 쏙”** 꺼낼 수 있게 되는 것이 핵심!

## 1️⃣ BeautifulSoup 설치

터미널에서 실행

```bash

```

- `requests` → 웹 요청
- `beautifulsoup4` → HTML 구조 분석
- `lxml` → HTML을 빠르고 안정적으로 파싱해주는 엔진

> 💡 왜 lxml을 같이 깔까?
> BeautifulSoup 자체는 “파서를 감싸는 래퍼”이고,
> 실제로 HTML을 분석해주는 엔진은 `lxml`, `html.parser`, `html5lib` 같은 것들이라서
> **성능이 좋은 lxml**을 함께 설치해 두는 게 좋습니다.

## 2️⃣ 페이지 제목 가져오기

연습 사이트: `https://quotes.toscrape.com/`

파일명: `quotes_title.py`
```python
import requests
from bs4 import BeautifulSoup

url = "https://quotes.toscrape.com/"
resp = requests.get(url)
resp.raise_for_status()

soup = BeautifulSoup(resp.text, "lxml")

title_tag = soup.select_one("h1") # <title>
print("페이지 제목:", title_tag.text)
```

### 코드 한 줄씩 이해하기

- `requests.get(url)`
    → 브라우저가 주소창에 입력하는 것과 비슷한 역할
    → “이 주소 페이지 HTML 좀 줘!” 라고 요청
    
- `resp.raise_for_status()`
    → 응답 코드가 200이 아니면(404, 500 등) 에러를 발생시켜서 문제 상황을 바로 알 수 있게 해줌
    
- `BeautifulSoup(resp.text, "lxml")`
    → `resp.text` : 긴 문자열 형태의 HTML
    → 이를 태그 단위로 쪼개서 다루기 편한 객체로 바꿔줌
    
- `soup.select_one("title")`
    → CSS 선택자 방식으로 `<title>` 태그 하나를 찾아옴
    → 여러 개가 있으면 첫 번째 것만
    
- `title_tag.text`
    → `<title>여기 안에 있는 글자</title>` 에서 **텍스트만** 꺼내기
    

📝 실행
```bash
python quotes_title.py
```

📝 실행 결과 예시
```
페이지 제목: Quotes to Scrape
```

**“웹 요청 → HTML 받기 → 태그 찾기 → 텍스트 출력”** 흐름을 한 번 경험한 상태입니다.

## 3️⃣ 명언 목록 중 **첫 번째 명언만** 가져오기

이제 `<title>`이 아니라, 실제 페이지에 있는 “명언 목록” 영역에서

맨 위(첫 번째) 명언을 뽑아봅니다.

이 사이트 구조(개략):
```html
<divclass="quote">
<spanclass="text">“명언 내용…”</span>
<span>by<smallclass="author">저자이름</small></span>
    ...
</div>
```

파일명: `quotes_one.py`
```python
import requests
from bs4 import BeautifulSoup

url ="https://quotes.toscrape.com/"
resp = requests.get(url)
resp.raise_for_status()
soup = BeautifulSoup(resp.text,"lxml")

# 첫 번째 명언 블록 선택
quote = soup.select_one("div.quote")

# 명언 내용과 저자 태그 선택
text_tag = quote.select_one("span.text") # 첫번째 1개만 들고오는 메서드
author_tag = quote.select_one("small.author")

print("첫 번째 명언:")
print("내용:", text_tag.text.strip())
print("저자:", author_tag.text.strip())
```

- `div.quote`
    - `<div class="quote"> ... </div>` 한 덩어리가 **명언 1개**
- `quote.select_one("span.text")`
    - 그 안에서 `<span class="text">` 부분 찾기 → 명언 문장
- `quote.select_one("small.author")`
    - `<small class="author">` → 저자 이름

📝 실행 결과 예시

```bash
python quotes_one.py
```

```
첫 번째 명언:
내용: “The world as we have created it is a process of our thinking. It cannot be changed without changing our thinking.”
저자: Albert Einstein
```

(실제 문구는 사이트 기본 첫 번째 명언입니다.)

## 4️⃣ 명언 목록 **전체** 가져오기

이번에는 첫 번째만 말고,

리스트 전체를 돌면서 명언 + 저자를 번호와 함께 출력해봅니다.

파일명: `quotes_list.py`

```python
import requests
from bs4 import BeautifulSoup

url = "https://quotes.toscrape.com/"
resp = requests.get(url)
resp.raise_for_status()

soup = BeautifulSoup(resp.text, "lxml")

quotes = soup.select("div.quote")

# 사용자 입력
n = int(input("보고 싶은 명언 번호 입력 (1~10): "))

# 범위 검사
if 1 <= n <= len(quotes):
    quote = quotes[n - 1]   # 리스트 인덱스 보정

    text = quote.select_one("span.text").text.strip()
    author = quote.select_one("small.author").text.strip()

    print(f"\n {n}번 명언")
    print(text, "-", author)
else:
    print("해당 번호는 존재하지 않습니다.")

-----------------------------------------

# 두 번째 것만 선택
second = quotes[1]

text = second.select_one("span.text").text.strip()
author = second.select_one("small.author").text.strip()

print("두 번째 명언")
print(text, "-", author)

---------------------------------------
print("현재 페이지 명언 목록")
print("=" * 40)

for i, quote in enumerate(quotes, start=1):
    text_tag = quote.select_one("span.text")
    author_tag = quote.select_one("small.author")

    if text_tag and author_tag:
        text = text_tag.text.strip()
        author = author_tag.text.strip()
        print(f"{i}. {text}  - {author}")
```

핵심 포인트

- `soup.select("div.quote")`
    - `class="quote"` 인 `<div>` 들을 **리스트**로 모두 가져옴
    - 리스트의 각 item = 명언 1개 블록
- `for i, quote in enumerate(quotes, start=1):`
    - `enumerate`는 (번호, 값)을 동시에 꺼내주는 도우미
    - `start=1` 로 해서 번호를 1부터 시작하게 함
- `text_tag.text.strip()`
    - `.text` : 태그 안의 글자만 뽑기
    - `.strip()` : 문자열 앞뒤 공백/줄바꿈 제거
