`settings.py` STATIC 설정
`STATICFILES_DIRS`와 `TEMPLATES['DIRS']` 경로를 아래와 같이 추가 설정:
```python
import os
BASE_DIR = Path(__file__).resolve().parent.parent

# 정적 파일
STATIC_URL = "static/"
STATICFILES_DIRS = [
    os.path.join(BASE_DIR, "static"), # ✔️ 외부 static 디렉토리 지정
]

# 템플릿 설정
TEMPLATES = [
    {
        ...
        'DIRS': [os.path.join(BASE_DIR, "templates")], # ✔️ 외부 templates 디렉토리 지정
        'APP_DIRS': True,
        ...
    },
]

```
