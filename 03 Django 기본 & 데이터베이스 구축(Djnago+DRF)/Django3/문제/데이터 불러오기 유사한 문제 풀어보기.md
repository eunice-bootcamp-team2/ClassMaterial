models.py
`articles/models.py`
```python
from django.db import models


class Article(models.Model):
    title = models.CharField(max_length=200)
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.title


class Comment(models.Model):
    article = models.ForeignKey(
        Article,
        on_delete=models.CASCADE
    )
    content = models.CharField(max_length=300)

    def __str__(self):
        return self.content
```

# 2) views.py (정답 코드)

`articles/views.py`
```python
from django.shortcuts import render
from .models import Article, Comment

def article_list(request):
    article_list = Article.objects.all().order_by("-id")
    comment_list = Comment.objects.all().order_by("-id")
    comment = Comment.objects.first()
    context = {
	    "article_list": article_list,
        "comment_list": comment_list,
        "comment": comment,    
    }
    return render(request, "articles/articles.html", context)
```

# 4) 템플릿 만들기 (정답 코드)

경로 정확히:

`articles/templates/articles/articles.html`
```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <title>Article / Comment 연습 페이지</title>
</head>
<body>

  <!-- ======================= -->
  <!-- Article 전체 연습 -->
  <!-- ======================= -->

  <h1>Article 전체</h1>

  <h3>article_list 전체 출력</h3>
  <p>{{ article_list }}</p>

  <hr>

  <h3>Article 하나씩 꺼내기</h3>
  {% for article in article_list %}
    <p>title: {{ article.title }}</p>
    <p>id: {{ article.id }}</p>
    <p>{{ article }}</p>
    <p>--------------------</p>
  {% empty %}
    <p>Article이 없습니다.</p>
  {% endfor %}

  <hr>

  <!-- ======================= -->
  <!-- Comment 전체 연습 -->
  <!-- ======================= -->

  <h1>Comment 전체</h1>

  <h3>comment_list 전체 출력</h3>
  <p>{{ comment_list }}</p>

  <h3>Comment 하나씩 꺼내기</h3>
  {% for comment in comment_list %}
    <p>{{ comment.content }} (article_id: {{ comment.article_id }})</p>
  {% empty %}
    <p>Comment가 없습니다.</p>
  {% endfor %}

  <hr>

  <!-- ======================= -->
  <!-- Article → Comment 역참조 -->
  <!-- ======================= -->

  <h1>Article → Comment 역참조 연습</h1>

  {% for article in article_list %}
    <h3>Article: {{ article.title }}</h3>

    {% if article.comment_set.all %}
      {% for comment in article.comment_set.all %}
        <p>{{ comment.content }}</p>
      {% endfor %}
    {% else %}
      <p>이 Article에 연결된 Comment 없음</p>
    {% endif %}

    <p>--------------------</p>
  {% endfor %}

  <hr>

  <!-- ======================= -->
  <!-- Comment → Article 정참조 -->
  <!-- ======================= -->

  <h3>comment.article</h3>

  {% for comment in comment_list %}
    <p>Article 제목: {{ comment.article.title }}</p>
    <p>Comment 내용: {{ comment.content }}</p>
    <hr>
  {% endfor %}

  <hr>

  <!-- ======================= -->
  <!-- Comment 단일 객체 연습 -->
  <!-- ======================= -->

  <h3>한 개의 Comment 데이터</h3>

  {% if comment %}
    <p>{{ comment.content }}</p>
    <p>{{ comment.article.title }}</p>
  {% else %}
    <p>Comment 데이터가 없습니다.</p>
  {% endif %}

</body>
</html>
```

# (옵션) 관리자에서 보기 편하게(list_display)까지 개선

원하면 admin.py를 이렇게 바꿔도 좋아:
```python
from django.contrib import admin
from .models import Article, Comment

@admin.register(Article)
class ArticleAdmin(admin.ModelAdmin):
    list_display = ("id", "title", "created_at")
    search_fields = ("title",)
    ordering = ("-id",)

@admin.register(Comment)
class CommentAdmin(admin.ModelAdmin):
    list_display = ("id", "article", "content")
    search_fields = ("content",)
    ordering = ("-id",)
```
