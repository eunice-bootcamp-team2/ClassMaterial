# 0) 먼저 전체 흐름 한 줄 요약

1. **models.py**: DB 테이블 구조 정의 (Question, Choice)
2. **views.py**: DB에서 데이터를 꺼내서(dict로) 템플릿에 전달
3. **aa.html**: 전달받은 데이터를 `{{ }}` / `{% for %}`로 화면에 출력

# 1) views.py에서 “어떤 데이터”를 가져오나?

(지금 너의 `aa()` 뷰 기준)
```python
def aa(request):
    latest_question_list = Question.objects.all()
    choice_list = Choice.objects.all()

    context = {
        "latest_question_list": latest_question_list,
        "choice_list": choice_list,
    }

    return render(request, "polls/aa.html", context)
```
✅ 여기서 가져오는 데이터는 2개
- `latest_question_list`  
    → **Question 테이블의 전체 목록(QuerySet)**  
    → 예: [Question 1, Question 2, Question 3 …]
    
- `choice_list`  
    → **Choice 테이블의 전체 목록(QuerySet)**  
    → 예: [Choice 1, Choice 2, Choice 3 …]
    
그리고 이 2개를 **context 딕셔너리**로 템플릿에 전달해요.

| 표현                             | 실제 의미               |
| ------------------------------ | ------------------- |
| `{{ question }}`               | 객체 → 문자열(`__str__`) |
| `{{ question.question_text }}` | 필드 직접 접근            |
만약 __str__를 이렇게 바꾸면? 아래와 같이 출력됩니다.
```python
def __str__(self):
	# return self.question_text
	return f"{self.id} - {self.question_text} - {self.pub_date}"
```
![[Pasted image 20260119202353.png]]

✅ 1단계: Question 목록에서 하나 꺼내서 이름 붙이기
- `latest_question_list` 안에 들어있는 Question을
- 하나씩 꺼내서
- 그걸 `question`이라고 부르겠다
    

즉, 반복이 돌 때마다:
- 첫 번째 반복: `question = Question(id=1, ...)`
- 두 번째 반복: `question = Question(id=3, ...)`
- 세 번째 반복: `question = Question(id=4, ...)`
    
✅ 2단계: 꺼낸 Question에서 “필드” 출력
- `{{ question.question_text }}`  
    → Question 모델의 `question_text` 컬럼 값 (질문 문장)
    
- `{{ question.id }}`  
    → Django가 자동으로 만든 기본 PK(id)
    
- `{{ question }}`  
    → Question 객체 자체를 출력  
    → 내부적으로 `question.__str__()`를 호출  
    → 그래서 결국 `question_text`가 보이는 것처럼 느껴짐

# 7) Question → Choice 역참조(질문별로 보기 묶기)
```html
<h1>Question → Choice 역참조 연습</h1>
{% for question in latest_question_list %}
  <h3>Question: {{ question.question_text }}</h3>

  {% if question.choice_set.all %}
    {% for choice in question.choice_set.all %}
      <p>{{ choice.choice_text }}</p>
    {% endfor %}
  {% else %}
    <p>이 Question에 연결된 Choice 없음</p>
  {% endif %}
  <p>--------------------</p>
{% endfor %}
```
![[Pasted image 20260119203445.png]]
**Question을 하나 꺼내고 →  
그 Question에 연결된 Choice들만 다시 꺼내서 출력하는 구조**입니다.

🔹 1단계: 바깥 for문 (Question 꺼내기)
```html
{% for question in latest_question_list %}
```
- `latest_question_list` 안에 있는
- Question 객체를 하나씩 꺼내서
- 그걸 `question`이라는 이름으로 참조함

즉, 이 순간:
```
question = Question 객체 1개
```

🔹 2단계: 질문 제목 출력
```html
<h3>Question: {{ question.question_text }}</h3>
```
현재 보고 있는 Question의 **질문 내용**을 출력

🔹 3단계: if문 (이 질문에 연결된 Choice가 있나?)
```html
{% if question.choice_set.all %}
```
이 Question에 연결된 Choice가 하나라도 있으면
그 목록이
- 비어 있으면 → False
- 하나라도 있으면 → True

🔹 4단계: 안쪽 for문 (Choice 꺼내기)
```html
{% for choice in question.choice_set.all %}
```
- **지금 이 Question(question)에 연결된 Choice들만**
- 하나씩 꺼내서
- 그걸 `choice`라는 변수로 사용
즉, 이 반복 안에서는:
```
choice = Choice 객체 1개
```

🔹 5단계: Choice 출력
```html
<p>{{ choice.choice_text }}</p>
```

🔹 6단계: else (Choice가 하나도 없을 때)
```html
{% else %}
  <p>이 Question에 연결된 Choice 없음</p>
```

---
Choice가 Question을 ForeignKey로 참조하고 있기 때문에,  
Question 입장에서는 `choice_set`이라는 역참조 통로를 사용해야 한다.

1️⃣ Choice → Question : `choice.question`
###### Question 테이블
| id  | question_text |
| --- | ------------- |
| 1   | 오늘은 목요일 입니다.  |
| 2   | 당신이 좋아하는 계절은? |
###### Choice 테이블
|id|choice_text|question_id|
|---|---|---|
|1|기분이 좋다|1|
|2|기분이 나쁘다|1|
|3|봄|2|
Choice는 Question을 ForeignKey로 직접 참조하고 있습니다.

✅ 템플릿에서 사용
```html
<h3>choice.question</h3>
{% for choice in choice_list %}
  <p>{{ choice.question.question_text }}</p>  <!-- 이 choice가 속한 질문 -->
  <p>{{ choice.choice_text }}</p>            <!-- choice 자체 -->
  <hr>
{% endfor %}
```

views.py에서 `choice` 한 개를 따로 만들어서 넘기기

def aa(request):
    latest_question_list = Question.objects.all()
    choice_list = Choice.objects.all()

    choice = Choice.objects.first()  # 1개만

    context = {
        "latest_question_list": latest_question_list,
        "choice_list": choice_list,
        "choice": choice, # 한개의 초이스를 딕셔너리에 저장
    }
    return render(request, "polls/aa.html", context)
