◽ 마이그레이션(Migration)을 사용해서 모델(테이블)을 업데이트할 수 있어요.

⚠️ 주의할 점
- 컬럼을 추가할 때
    - 기존에 있는 데이터들에 대해 기본값(default) 을 채워줘야 합니다.
- 컬럼을 삭제할 때
    - 다른 코드에서 이 컬럼을 참조하고 있지 않은지 확인해야 합니다.

`마이그레이션 명령어`
```python
# 1. 마이그레이션 파일 생성 (Django에게 모델이 변경되었음을 알림)
python manage.py makemigrations

# 2. 마이그레이션 적용 (변경된 내용을 DB에 반영)
python manage.py migrate
```
---
◽ 모델 롤백 (Rollback the Model)
	모델을 변경한 후, 이전 테이블 구조로 되돌리고 싶을 때 사용하는 방법입니다.

💡 `롤백 명령어`
```python
# 형식
python manage.py migrate <앱 이름> <되돌릴 마이그레이션 파일 이름>

# 예시
python manage.py migrate polls 0001_initial
```

🔍 해설:
- `polls`는 롤백하려는 Django 앱 이름입니다.
- `0001_initial`은 롤백하고자 하는 마이그레이션 버전입니다.  
    → 이 명령은 현재 상태에서 `0001_initial` 시점으로 테이블 구조를 되돌립니다.
    
🛑 주의: 롤백은 데이터 손실이 발생할 수 있으니 신중하게 실행해야 합니다!

---
◽ VALIDATORS (검증기)
- Validator(검증기)는 값을 받아서, 조건을 만족하지 않으면 ValidationError를 발생시키는 함수입니다.
- 다양한 필드 타입에서 검증 로직을 재사용할 수 있어서 유용합니다.
[!공식 문서](https://docs.djangoproject.com/en/4.1/ref/validators/)

</>예시코드:
```python
from django.core.validators import (
    MaxLengthValidator,
    MinLengthValidator
)

class Question(models.Model):
    question_text = models.CharField(max_length=200)
    pub_date = models.DateTimeField('date published')
    owner = models.CharField(
        max_length=200,
        blank=True,
        validators=[
            MinLengthValidator(3),  # 최소 길이 3자 이상
            MaxLengthValidator(10)  # 최대 길이 10자 이하
        ]
    )
```

⚠️ 주의사항
- Validator는 `ModelForm`에서만 기본적으로 작동합니다.
- 모델 인스턴스에서 수동으로 검증하려면 `.full_clean()` 메서드를 호출해야 합니다.  
    → 그렇지 않으면 ValidationError가 발생하지 않습니다.

요약하자면, Validator는 필드값을 검증하는 도구이며,  
폼에서 자동 실행되지만, 모델 단독으로는 `full_clean()`을 사용해야 작동합니다.

◽ 레코드(데이터) 수정하기
	객체를 가져와서 값을 수정한 뒤 `save()` 메서드로 저장할 수 있습니다.
	
</> 예시코드:
```python
>>> from polls.models import Question # Question 모델 임포트
>>> q = Question.objects.get(pk=1)   # 기본키(pk)가 1인 객체 가져오기
>>> q                                # 현재 상태 확인
<Question: What's up?>

>>> q.question_text = "How are you?"  # 텍스트 수정
>>> q.save()                          # DB에 변경 내용 저장
>>> q
<Question: How are you?>
```

- `objects.get(pk=1)` → 기본키가 1인 레코드 조회
- `question_text` 속성 변경 → `"How are you?"`
- `.save()` → 변경된 내용을 실제 데이터베이스에 반영
---
◽ ❌ 레코드 삭제하기 (Delete the Record)
	객체를 가져와서 값을 확인한 뒤 `.delete()` 메서드로 삭제할 수 있음.

</>예시 코드:
```python
from django.utils import timezone      # 시간 관련 유틸 불러오기
now = timezone.now()                  # 현재 시간 저장

# 새로운 질문 객체 생성
q = Question(question_text="how old are you?", pub_date=now)
q.save()                              # DB에 저장

Question.objects.all()               # 현재 저장된 모든 질문 조회
# 결과: <Question: How are you?>, <Question: how old are you?>
```

```python
# pk=2 (기본키가 2번인 객체) 가져오기
q = Question.objects.get(pk=2)
q.delete()                           # 삭제 실행

Question.objects.all()               # 다시 조회
# 결과: <Question: How are you?>
```
- `Question.objects.get(pk=2)` → 기본키 2인 객체를 가져옴
- `.delete()` → 해당 객체 삭제
- 삭제 후 다시 `objects.all()`로 조회하면 해당 객체는 사라진 것을 확인할 수 있음
