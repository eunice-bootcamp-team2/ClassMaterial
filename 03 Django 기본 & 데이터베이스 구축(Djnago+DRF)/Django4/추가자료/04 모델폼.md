모델 폼(ModelForm)은 Django에서 모델(Model)을 기반으로 자동으로 폼(Form)을 생성해주는 기능입니다.  
즉, 이미 만들어둔 모델 클래스를 이용해서 폼을 따로 만들지 않고도 쉽게 입력 폼을 만들 수 있게 해주는 도구입니다.

폴더/파일 구조예시:
```python
myproject/
├── polls/               # 앱 디렉토리
│   ├── models.py        # 모델 정의
│   ├── forms.py         # 모델폼 정의 (직접 생성)
│   ├── views.py         # 폼 처리
│   ├── urls.py          # URL 연결
│   └── templates/
│       └── polls/
│           └── survey_form.html  # 템플릿
├── manage.py
└── myproject/
    └── settings.py
```

✅ `models.py` – 모델 정의 polls/models.py
```python
from django.db import models

class Question(models.Model):
    question_text = models.CharField(max_length=200)
    pub_date = models.DateTimeField("date published")

    def __str__(self):
        return self.question_text

class Choice(models.Model):
    question = models.ForeignKey(Question, on_delete=models.CASCADE)
    choice_text = models.CharField(max_length=200)
    votes = models.IntegerField(default=0)

    def __str__(self):
        return self.choice_text
```

✅ `forms.py` 파일은 직접 생성해야 합니다! polls/forms.py
```python
from django import forms
from .models import Question, Choice

class QuestionForm(forms.ModelForm):
    class Meta:
        model = Question
        fields = ['question_text', 'pub_date']  # 사용할 필드

class ChoiceForm(forms.ModelForm):
    class Meta:
        model = Choice
        fields = ['question', 'choice_text', 'votes']
```

✅ 뷰에서 ModelForm 사용 (`views.py`)
```python
from django.shortcuts import render, redirect
from .forms import QuestionForm, ChoiceForm

def create_question(request):
    if request.method == 'POST':
        form = QuestionForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('question-list')  
            # 성공 시 다른 페이지로 이동
    else:
        form = QuestionForm()
    return render(request, 'polls/create_question.html', {'form': form})

def create_choice(request):
    if request.method == 'POST':
        form = ChoiceForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('choice-list')
    else:
        form = ChoiceForm()
    return render(request, 'polls/create_choice.html', {'form': form})
```

✅ URL 연결 (`urls.py`) polls/urls.py
```python
from django.urls import path
from . import views

urlpatterns = [
    path('question/create/', views.create_question, name='create-question'),
    path('choice/create/', views.create_choice, name='create-choice'),
]
```

🔸 모델폼이 왜 필요할까?
- 일반적인 폼을 만들려면 `forms.Form`을 사용하여 필드를 하나하나 직접 작성해야 합니다.
- 하지만 `ModelForm`을 사용하면 기존 모델의 필드 정보를 그대로 사용해서 폼을 자동으로 만들어줍니다.
- 코드가 간결해지고, 모델과 폼이 자동으로 연결되니 유지보수도 쉽습니다.

1️⃣ ModelForm 기본 구성
- `Survey`라는 모델을 정의합니다.
    - `user_name`: 문자열(CharField), 최대 200자
    - `user_age`: 정수(IntegerField)
- `SurveyForm`이라는 클래스를 만들고 `ModelForm`을 상속받습니다.
- 내부에 `Meta` 클래스를 정의해서 어떤 모델(`model = Survey`)을 기준으로 만들 것인지 지정하고, 포함할 필드를 `fields = ['user_name', 'user_age']`로 설정해요.

2️⃣ ModelForm 사용하기
- 사용자 입력을 받을 땐 `request.POST`로 폼 데이터를 가져와서 `SurveyForm`에 넣습니다.
- `.is_valid()`를 이용해 입력값이 유효한지 검사합니다.
- 유효하다면 `.save()`로 DB에 저장할 수 있어요.

✨ 요약: 유효성 검사 후 → `form.save()` 호출로 간단하게 저장 가능!

3️⃣ ModelForm 스타일 적용
- `widgets`: 각 필드의 입력창을 어떻게 보여줄지 지정할 수 있어요.
- Bootstrap의 `form-control` 클래스를 적용하면 폼 스타일을 이쁘게 꾸밀 수 있어요.
- `labels`: 필드명을 사용자에게 더 친절한 이름으로 보여줄 수 있어요.
	예: `user_name` → “User Name”으로 출력되도록 설정

4️⃣ ModelForm 유효성 검사 (Validator)
- 모델에 `validators` 옵션을 추가하면 값의 범위나 조건을 지정할 수 있어요.
    - `MinValueValidator(1)` : 최소값 1
    - `MaxValueValidator(100)` : 최대값 100
- 이 설정은 모델에서 직접 유효성을 체크할 수 있도록 도와줘요.
	예: `user_age`가 1~100 사이가 아니면 에러 발생
