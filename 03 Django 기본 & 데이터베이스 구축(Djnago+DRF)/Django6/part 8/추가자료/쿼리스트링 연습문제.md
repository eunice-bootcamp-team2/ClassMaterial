```python
def parse_yyyy_mm_dd(value: str):
    """
    'YYYY-MM-DD' → date로 변환
    실패하면 None
    """
    try:
        return datetime.date.fromisoformat(value)
    except (TypeError, ValueError):
        return None
```

2️⃣ 연습 2: 검색어가 있을 때만 필터하기

✅ 학생 목표
- `q`가 있을 때만 `icontains` 필터 적용
- `q`가 없으면 전체 목록 그대로

문제(빈칸)
```python
def practice_2(request):
    qs = Question.objects.all()
    q = __________________________  # q 꺼내기

    if __________________________:  # q가 있을 때만
        qs = qs.filter(question_text__icontains=q)

    # 결과 개수만 화면에 보여주기
    return HttpResponse(f"검색어: {q} / 결과 개수: {qs.count()}")

def practice_api_2(request):
    qs = Question.objects.all()
    q = __________________________

    if __________________________:
        qs = qs.filter(question_text__icontains=q)

    return JsonResponse({
        "q": q,
        "count": qs.count(),
        "results": [{"id": x.id, "text": x.question_text} for x in qs[:10]]
    })
```

✅ 정답
```python
def practice_2(request):
    qs = Question.objects.all()
    q = request.GET.get("q")

    if q:
        qs = qs.filter(question_text__icontains=q)

    return HttpResponse(f"검색어: {q} / 결과 개수: {qs.count()}")

def practice_api_2(request):
    qs = Question.objects.all()
    q = request.GET.get("q")

    if q:
        qs = qs.filter(question_text__icontains=q)

    return JsonResponse({
        "q": q,
        "count": qs.count(),
        "results": [{"id": x.id, "text": x.question_text} for x in qs[:10]]
    })
```

이 코드의 해석:
```python
if q:
	qs = qs.filter(question_text__icontains=q)
```
	질문 글자(question_text) 안에 사용자가 입력한 q가 포함된 것만 남겨라 는 뜻입니다.
	.filter()는 조건에 맞는것만 골라라는뜻의 메서드입니다.

`question_text__icontains=q` 이건 Django만의 문법입니다. 구조를 나누면:
```
필드명 __ 조건 = 값
```
- `question_text` : 모델의 필드명
- `__` (언더바 2개) : 조건을 붙이겠다는 약속된 문법
- `icontains` : 조건 이름으로 
	- `contains` → 포함하겠다는 뜻이고 
	- `i` → 대소문자 무시 (insensitive)
	- 즉, 대소문자 구분 없이, 이 글자가 포함되어 있으면 이라는 뜻입니다.
- `= q` : 비교할 값
전체를 해석하면:
질문 목록(qs) 중에서 question_text 안에 사용자가 입력한 q가 들어있는 것만 남겨라 라는 뜻입니다.

실제 데이터를 확인한 후 q에 실제데이터의 한글자를 브라우저에 입력 후 확인한 결과:

5️⃣ 연습문제 5 : “날짜 start / end 필터”

✅ 목표
- `start=YYYY-MM-DD`가 오면 그 날짜 이후만
- `end=YYYY-MM-DD`가 오면 그 날짜 이전만

```python
def practice_5(request):

    start = parse_yyyy_mm_dd(start_raw)
    end = parse_yyyy_mm_dd(end_raw)

    if __________________________:
        qs = qs.filter(pub_date__date__gte=start)

    if __________________________:
        qs = qs.filter(pub_date__date__lte=end)

    return HttpResponse(f"start={start} end={end} / 결과:{qs.count()}")

def practice_api_5(request):
    qs = Question.objects.all()
    start_raw = __________________________
    end_raw = __________________________

    start = parse_yyyy_mm_dd(start_raw)
    end = parse_yyyy_mm_dd(end_raw)

    if __________________________:
        qs = qs.filter(pub_date__date__gte=start)
    if __________________________:
```

✅ 정답
```python
def practice_5(request):
    qs = Question.objects.all()

        qs = qs.filter(pub_date__date__gte=start)
    if end:
        qs = qs.filter(pub_date__date__lte=end)

        "start_raw": start_raw,
```
