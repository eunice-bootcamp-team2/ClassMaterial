✨ CLI(Command Line Interface) : 
	명령줄 인터페이스로, 사용자가 터미널에 직접 텍스트 명령어를 입력하여 컴퓨터와 상호작용하는 방식입니다.  
	GUI(그래픽 사용자 인터페이스)와 달리 마우스 없이 명령어만으로 작업을 수행합니다.

사전 준비: uv 설치 (처음 한 번만) : 이미 설치했으면 안해도 됩니다.
```bash
pip install uv
```
한 번 설치해두면 이후 프로젝트마다 재사용합니다.

✅ 작업용 폴더 만들기 (uv 버전)
```bash
mkdir Django_first
cd Django_first

# uv로 가상환경 생성
uv venv .venv

# 가상환경 활성화
source .venv/bin/activate      # macOS / Linux

# Django 설치 (uv 방식)
uv add django

# 디렉토리 삭제가 필요한 경우
deactivate               # (가상환경 안에 있을 경우 먼저 비활성화)
cd ~/your_project        # 가상환경이 있는 폴더로 이동
rm -rf .venv             # 가상환경 삭제
```

	Django는 Python 기반이므로, 먼저 Python이 설치되어 있어야 합니다.
```bash
# 설치된 파이썬 버전 확인
python --version
```

✅ 2단계. 가상환경(Virtual Environment) 만들기
```bash
# 경로 확인 예시
(venv) youjung@DESKTOP-PJCRMMU:~/Django_OfficialDocumentTutorial/

# uv로 가상환경 생성
uv venv .venv

# 잘못 만들어진 가상환경 지우기
rm -rf .venv

# 가상환경 활성화
source .venv/bin/activate     # macOS/Linux
# .\.venv\Scripts\Activate.ps1 # Windows (PowerShell)
```
https://docs.djangoproject.com/ko/5.2/howto/windows/#using-python-s-venv

가상환경 재생성
```python
# 가상환경 폴더 삭제
rm -rf .venv

# 새로 가상환경 생성 (Python 3.x 버전에 맞게)
uv venv .venv

# 가상환경 활성화
source .venv/bin/activate      # 또는 Windows용 활성화 명령

# (선택) pip 최신화 - uv를 통해 실행
uv pip install --upgrade pip

# Django 설치 (uv 방식)
uv add django

# requirements.txt 파일 기반으로 패키지 설치
uv pip install -r requirements.txt

# 설치된 패키지 목록 확인
uv pip list
```

✅ 3단계. Django 설치: 반드시 가상환경 안에서 장고를 install합니다.
```python
# (가상환경 활성화된 상태에서)
uv add django
```
https://docs.djangoproject.com/ko/5.2/intro/install/#install-django

🧐설치확인
```bash
python -m django --version
```

🧾 보충설명:
	장고 프로젝트를 새로 개발할때마다 가상환경안에 장고를 새로 설치합니다.
	(각 프로젝트는 자신의 `.venv` + Django 세트를 가지는 게 좋습니다.)

✅ 4단계. Django 프로젝트 시작
```bash
django-admin startproject mysite .   # [전체 플랫폼 또는 서비스의 이름]
cd mysite  # (여기서는 점(.)을 썼으므로 실제로는 이미 현재 폴더가 프로젝트 루트)
```

◽ 프로젝트 구조는 다음과 같습니다:
```python
├── manage.py
├── mysite/
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   ├── wsgi.py
│   └── asgi.py
```

✅ 5단계. 개발 서버 실행: 서버 주소: http://127.0.0.1:8000/
```bash
python manage.py runserver
```
