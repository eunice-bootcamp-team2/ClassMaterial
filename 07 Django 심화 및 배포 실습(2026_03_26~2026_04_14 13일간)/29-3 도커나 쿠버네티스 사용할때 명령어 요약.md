### ✔️ Kubernetes 사용할 때 (Minikube)
```bash
docker compose down # 기존 컨테이너 종료  
minikube start --driver=docker  
kubectl apply -f k8s/
```

기존 컨테이는 종료해도 반드시 도커 엔진은 켜있어야 합니다.

도커 엔진이 켜있는지 확인하는 명령어
```bash
docker ps
```
✅ 켜져 있을 때
```
CONTAINER ID IMAGE COMMAND ...
```
❌ 꺼져 있을 때
```
Cannot connect to the Docker daemon
```
도커 엔진 시작/종료
```bash
sudo systemctl start docker # 도커엔진 시작
sudo systemctl stop docker  # 도커엔진 종료
```

### ✔️ Docker Compose 사용할 때
```bash
docker compose up -d
```

둘은 완전히 다른 실행 방식
```bash
Docker Compose → 직접 실행  
Kubernetes → 관리해서 실행
```
둘다 띄우면 같은 앱을 두번 띄우는 상황이 됩니다.
