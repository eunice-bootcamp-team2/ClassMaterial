기존 Todo를 아무나 보는 구조에서  
로그인한 사용자 본인 것만 CRUD 하도록 바꾸면 됩니다.  

즉, 핵심은 `Todo`에 `user_id`를 붙이고, 모든 Todo API에서 `get_current_user()`를 사용하면 돼요. 이 흐름은 앞서 정리된 DB/session 구조, 회원가입, JWT 로그인 구현 위에 이어서 붙는 단계예요.

`app/models/todo.py` 수정
```python
from sqlalchemy import Column, Integer, String, Boolean, ForeignKey # ✅ 추가
from app.db.base import Base


class TodoDB(Base):
    __tablename__ = "todos"

    id = Column(Integer, primary_key=True, index=True)
    title = Column(String(100), nullable=False, index=True)
    done = Column(Boolean, default=False)

    # ✅ 추가: 어떤 사용자의 Todo인지 저장
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False, index=True)
```
이제 Todo 한 개마다 “누구 것인지” 저장됩니다.

`app/schemas/todo.py` 수정
```python
from pydantic import BaseModel, Field
from typing import Optional


class TodoCreate(BaseModel):
    title: str = Field(..., min_length=1, max_length=100, description="할 일 제목")
    done: bool = False


class TodoUpdate(BaseModel):
    title: Optional[str] = Field(
        None,
        min_length=1,
        max_length=100,
        description="수정할 할 일 제목"
    )
    done: Optional[bool] = None


class Todo(BaseModel):
    id: int
    title: str
    done: bool
    user_id: int   # ✅ 추가

    class Config:
        from_attributes = True
```

`app/routes/item.py` 수정 : 이제부터 Todo API는 전부 로그인 필요로 바꿉니다.
```python
from fastapi import APIRouter, HTTPException, status, Query, Depends
from typing import Optional
from sqlalchemy.orm import Session

from app.schemas.todo import Todo, TodoCreate, TodoUpdate
from app.models.todo import TodoDB
from app.models.user import UserDB # ✅ 추가
from app.db.session import get_db

# ✅ 추가: 로그인 사용자 가져오는 함수 import
from app.routes.user import get_current_user

router = APIRouter(prefix="/todos", tags=["Todos"])


# ✅ 내 Todo 목록 조회
@router.get(
    "",
    response_model=list[Todo],
    status_code=status.HTTP_200_OK
)
def get_todos(
    keyword: Optional[str] = Query(None, min_length=1, max_length=100, description="제목 검색"),
    done: Optional[bool] = Query(None, description="완료 여부"),
    sort: Optional[str] = Query(None, description="asc 또는 desc"),
    db: Session = Depends(get_db),
    current_user: UserDB = Depends(get_current_user),   # ✅ 로그인 필요
):
    # ✅ 수정: 내 것만 조회
    query = db.query(TodoDB).filter(TodoDB.user_id == current_user.id)

    if keyword is not None:
        query = query.filter(TodoDB.title.ilike(f"%{keyword}%"))

    if done is not None:
        query = query.filter(TodoDB.done == done)

    if sort is not None and sort not in ["asc", "desc"]:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="sort 값은 asc 또는 desc만 사용할 수 있습니다."
        )

    if sort == "asc":
        query = query.order_by(TodoDB.id.asc())
    elif sort == "desc":
        query = query.order_by(TodoDB.id.desc())
    else:
        query = query.order_by(TodoDB.id.asc())

    return query.all()


# ✅ 수정: 내 Todo 상세 조회
@router.get("/{todo_id}", response_model=Todo)
def get_todo(
    todo_id: int,
    db: Session = Depends(get_db),
    current_user: UserDB = Depends(get_current_user) # ✅ 로그인 필요
):
    todo = (
        db.query(TodoDB)
        .filter(TodoDB.id == todo_id, TodoDB.user_id == current_user.id)
        .first()
    )

    if not todo:
        raise HTTPException(status_code=404, detail="해당 할 일이 없습니다.")

    return todo


# ✅ 수정: 내 Todo 생성
@router.post("", response_model=Todo, status_code=201)
def create_todo(
    todo_data: TodoCreate,
    db: Session = Depends(get_db),
    current_user: UserDB = Depends(get_current_user)   # ✅ 로그인 필요
):
    # ✅ 같은 사용자 안에서만 제목 중복 검사
    existing_todo = (
        db.query(TodoDB)
        .filter(
            TodoDB.title == todo_data.title,
            TodoDB.user_id == current_user.id
        )
        .first()
    )

    if existing_todo:
        raise HTTPException(
            status_code=400,
            detail="같은 제목의 할 일이 이미 존재합니다."
        )

    new_todo = TodoDB(
        title=todo_data.title,
        done=todo_data.done,
        user_id=current_user.id
    )   # ✅ 로그인한 사용자 id 저장

    db.add(new_todo)
    db.commit()
    db.refresh(new_todo)

    return new_todo


# ✅ 내 Todo 수정
@router.put("/{todo_id}", response_model=Todo)
def update_todo(
    todo_id: int,
    todo_data: TodoUpdate,
    db: Session = Depends(get_db),
    current_user: UserDB = Depends(get_current_user),   # ✅ 로그인 필요
):
    update_data = todo_data.model_dump(exclude_unset=True)

    if not update_data:
        raise HTTPException(
            status_code=400,
            detail="수정할 데이터를 하나 이상 보내주세요."
        )

    # ✅ 내 Todo만 수정 가능
    todo = (
        db.query(TodoDB)
        .filter(TodoDB.id == todo_id, TodoDB.user_id == current_user.id)
        .first()
    )

    if not todo:
        raise HTTPException(status_code=404, detail="수정할 할 일이 없습니다.")

    if "title" in update_data:
        duplicate_todo = (
            db.query(TodoDB)
            .filter(
                TodoDB.title == update_data["title"],
                TodoDB.user_id == current_user.id,
                TodoDB.id != todo_id
            )
            .first()
        )
        if duplicate_todo:
            raise HTTPException(
                status_code=400,
                detail="같은 제목의 다른 할 일이 이미 존재합니다."
            )

    for key, value in update_data.items():
        setattr(todo, key, value)

    db.commit()
    db.refresh(todo)

    return todo


# ✅ 내 Todo 삭제
@router.delete("/{todo_id}", status_code=200)
def delete_todo(
    todo_id: int,
    db: Session = Depends(get_db),
    current_user: UserDB = Depends(get_current_user),   # ✅ 로그인 필요
):
    todo = (
        db.query(TodoDB)
        .filter(TodoDB.id == todo_id, TodoDB.user_id == current_user.id)
        .first()
    )

    if not todo:
        raise HTTPException(status_code=404, detail="삭제할 할 일이 없습니다.")

    deleted_data = {
        "id": todo.id,
        "title": todo.title,
        "done": todo.done,
        "user_id": todo.user_id
    }

    db.delete(todo)
    db.commit()

    return {
        "message": "삭제 완료",
        "deleted": deleted_data
    }
```

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from fastapi.exceptions import RequestValidationError
from fastapi.middleware.cors import CORSMiddleware
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates

from app.routes.item import router as item_router
from app.routes.user import router as user_router

from app.core.settings import settings
from app.db.init_db import init_db

init_db()

app = FastAPI(
    title=settings.PROJECT_NAME,
    description="FastAPI + SQLAlchemy 기반 Todo CRUD API",
    version=settings.VERSION
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.ALLOWED_ORIGINS,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

app.include_router(item_router)
app.include_router(user_router)

app.mount("/static", StaticFiles(directory="static"), name="static")
templates = Jinja2Templates(directory="app/templates")


@app.get("/")
def home():
    return {"message": "FastAPI Todo API 실행 중 (인증 기반 Todo 보호 완료)"}


@app.get("/page")
def todo_page(request: Request):
    return templates.TemplateResponse(
        "index.html",
        {"request": request}
    )


@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    return JSONResponse(
        status_code=422,
        content={
            "message": "입력값 검증에 실패했습니다.",
            "errors": exc.errors()
        }
    )

### 핵심 변화 한 줄 정리

이전:
- 모든 사용자가 같은 Todo 목록을 봄
    
지금:
- 로그인한 사용자만 접근 가능
- 자기 Todo만 조회/생성/수정/삭제 가능
    
즉 이 단계가 바로 인증 기반 API 보호예요.  
JWT 로그인 구현 위에 `Depends(get_current_user)`를 붙여서 보호한 것입니다.

주의할 점 하나는, 기존 `todos` 테이블에 `user_id`가 없던 상태라면 SQLite에서는 테이블을 새로 만들거나 DB를 초기화하는 편이 가장 쉽습니다. 지금 구조는 학습용으로 충분하고, 다음 단계에서는 비밀번호 해시를 `sha256` 대신 `passlib[bcrypt]`로 바꾸면 더 좋아요.
