- Swagger UI를 통해 API 문서를 확인합니다.
- Swagger 화면에서 Todo CRUD API를 직접 실행하여 정상 동작 여부를 테스트합니다.

`http://127.0.0.1:8000/docs` CRUD를 테스트 합니다.
![[Pasted image 20260313190308.png]]

(1) 전체 조회 API : GET `http://127.0.0.1:8000/todos`
```JSON
[
  {
    "id": 1,
    "title": "공부하기",
    "done": false
  },
  {
    "id": 2,
    "title": "운동하기",
    "done": true
  }
]
```

(2) 상세 조회 POST : `http://127.0.0.1:8000/todos/1`

(3) 생성 GET : `http://127.0.0.1:8000/todos/`
```JSON
{
  "title": "FastAPI 공부하기",
  "done": false
}
```

(4) 수정 PUT : `http://127.0.0.1:8000/1`
```JSON
{
  "id": 1,
  "title": "FastAPI 공부하기",
  "done": false
}
```

(5) 삭제 DELETE : `http://127.0.0.1:8000/1`
- 아이디를 통해 생성된 데이터를 삭제하고

(6) 첫페이지 GET : `http://127.0.0.1:8000/`
- 삭제가 되었는지 확인합니다.
