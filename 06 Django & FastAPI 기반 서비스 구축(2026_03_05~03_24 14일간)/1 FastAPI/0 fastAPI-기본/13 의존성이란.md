### 의존성이란? (Dependency)
	어떤 함수나 클래스가 다른 기능이나 코드의 도움을 받아 동작할 때, 그 외부 기능을 의미합니다.

쉽게 말해, 프로그램을 만들 때 매번 같은 코드를 반복해서 작성하지 않고, 공통으로 사용하는 
기능을 따로 만들어 두고 필요할 때 가져다 사용하는 방식입니다.

예를 들어 다음과 같은 기능들은 여러 곳에서 반복해서 사용될 수 있습니다.
- 사용자 인증 확인
- 데이터베이스 연결
- 요청 정보 처리
- 공통 설정 값
    
이러한 기능을 한 파일에 공통 코드로 만들어 두고,  
필요한 곳에서 불러와 사용하면 코드의 중복을 줄이고 관리도 쉬워집니다.

즉, 의존성은
> 여러 곳에서 사용하는 공통 기능을 미리 만들어 두고 필요할 때 가져와 사용하는 구조라고 이해하시면 됩니다.


의존성은 왜 필요한가?
1. 중복 제거
	여러 함수에서 같은 파라미터나 로직이 필요할 때, 매번 똑같이 작성하면 비효율적이죠.  
	→ 이걸 한 군데로 모아서 `Depends()`로 가져오면 훨씬 깔끔해요.
	
2. 코드 재사용성
	특정 기능(예: 인증, 공통 쿼리 파라미터 등)을 여러 곳에서 재활용할 수 있어요.
	
3. 유지보수 쉬움
	의존성을 함수로 분리해두면 나중에 수정이 필요할 때 한 군데만 수정하면 돼요.
	
4. 순서 제어	
	먼저 실행되어 선처리 가능
	
5. 테스트 편의	
	가짜 의존성으로 교체 가능 (mocking)
	
6. 문서 자동화	
	Swagger 문서에 자동 반영
	
7. 보안 처리	
	인증, 권한 확인을 중앙 집중 관리
	
8. 자원 관리	
	DB, 파일 등 자원 연결 → 해제 흐름을 의존성으로 구현 가능

---
일반함수 호출과 비교하여 설명하겠습니다:

`일반 함수 호출`
```python
def read_items():
    user = get_current_user()
    return {"user": user}
    
    
    
read_items()    
```
→ 내가 직접 불러야 해요.  
→ `get_current_user()`를 안 쓰면 동작 안 해요.

`의존성 주입 사용`
```python
from fastapi import Depends

@app.get("/items/")
def read_items(user = Depends(get_current_user)):
    return {"user": user}
```
→ FastAPI가 알아서:
- `get_current_user()` 먼저 실행
- `user`에 그 값을 넣어줌
- 우리는 그냥 `user`만 쓰면 됨

한마디로 요약하면 
내가 함수호출을 해서 부르느냐, FastAPI가 대신 부르고 관리해주느냐, 의 차이입니다

### 실습해보기

디렉토리 구조
```
myproject/
├── main.py
└── dependencies/
    ├── __init__.py
    └── common.py
```

`dependencies/common.py`
```python
from fastapi import Depends
from typing import Annotated


async def common_parameters(
    q: str | None = None,
    skip: int = 0,
    limit: int = 100
):
    """
    여러 API에서 공통으로 사용할 쿼리 파라미터 의존성
    """
    return {
        "q": q,
        "skip": skip,
        "limit": limit
    }


CommonsDep = Annotated[dict, Depends(common_parameters)]
```

`Annotated`란?
`Annotated`는 기본 타입 정보에 추가 설명이나 동작 정보를 함께 붙일 수 있게 해주는 문법입니다.

형식은 다음과 같습니다.
```
Annotated[기본타입, 부가정보]
```
FastAPI에서는 이를 사용해
- 이 값의 기본 타입이 무엇인지
- 이 값을 어떤 방식으로 주입할 것인지를 함께 표현할 수 있습니다.

예를 들어
```python
Annotated[dict, Depends(common_parameters)]
```
- 이 값은 `dict` 형태이고
- `common_parameters()` 의 결과를 `Depends` 로 주입받는다는 뜻입니다.
    
즉, `dict` 로 작성한 이유는 `common_parameters()` 함수가 딕셔너리 형태를 반환하기 때문입니다.

`main.py`
```python
from fastapi import FastAPI
from dependencies.common import CommonsDep

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "FastAPI Dependency Practice"}


@app.get("/items/")
async def read_items(commons: CommonsDep):
    """
    상품 목록 API
    공통 의존성(common_parameters)을 주입받아 사용
    """
    return {
        "endpoint": "items",
        "commons": commons
    }


@app.get("/users/")
async def read_users(commons: CommonsDep):
    """
    사용자 목록 API
    같은 의존성을 재사용
    """
    return {
        "endpoint": "users",
        "commons": commons
    }
```

이 코드가 의미하는 것

사용자가 예를 들어 아래처럼 요청하면
```
GET /items/?q=apple&skip=2&limit=10
```

FastAPI가 먼저
```
common_parameters(q="apple", skip=2, limit=10)
```
를 실행하고, 그 결과를 `commons` 에 넣어줍니다.

즉 `read_items()` 안에서는 직접 `q`, `skip`, `limit` 를 하나씩 받지 않고,  
공통 의존성 결과를 한 번에 받아서 사용하게 됩니다.
