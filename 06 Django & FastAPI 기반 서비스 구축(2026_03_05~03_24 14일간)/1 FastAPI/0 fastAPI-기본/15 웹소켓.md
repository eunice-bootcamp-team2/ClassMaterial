
### 1️⃣ 웹소켓(WebSocket) 개요

웹소켓(WebSocket)이란?  
브라우저(클라이언트)와 서버가 연결을 계속 유지하면서 실시간으로 데이터를 주고받는 통신 방식입니다.
일반적인 웹 통신은 HTTP 요청 → 응답 → 연결 종료 구조입니다.

하지만 웹소켓은 다음과 같습니다.
```
연결 요청 → 연결 유지 → 실시간 양방향 통신
```
즉,
- 서버 → 클라이언트
- 클라이언트 → 서버
    
둘 다 언제든지 데이터를 보낼 수 있는 구조입니다.

### 2️⃣ HTTP 방식과 WebSocket 차이

HTTP 방식:
웹페이지 대부분은 HTTP 방식입니다.
```
클라이언트 → 요청 → 서버  
서버 → 응답 → 클라이언트  
연결 종료
```
예
```
페이지 새로고침  
게시글 조회  
상품 목록 조회
```
문제
- 매번 연결해야 함
- 실시간 통신 불가능

WebSocket 방식:
웹소켓은 한번 연결하면 유지됩니다.
```
연결 요청  
↓  
연결 유지  
↓  
실시간 데이터 교환
```
예
```
채팅 메시지  
실시간 게임  
주식 가격  
라이브 방송
```

### 3️⃣ WebSocket 동작 과정
	웹소켓은 처음에는 HTTP로 시작합니다.

`1단계`
클라이언트가 서버에게 요청
```
HTTP Upgrade 요청
```

예
```
GET /ws HTTP/1.1  
Upgrade: websocket
```

`2단계`
서버가 웹소켓 연결 허용
```
HTTP 101 Switching Protocols
```

`3단계`
이후에는 웹소켓 프로토콜로 통신
```
클라이언트 ↔ 서버
```
연결이 유지됩니다.

### 4️⃣ WebSocket 데이터 처리 방식
	웹소켓은 보통 DB를 거치지 않고 메모리에서 처리되는 경우가 많습니다.

예 : 채팅
```
사용자 A 메시지 입력  
↓  
서버 메모리  
↓  
다른 사용자에게 즉시 전송
```
이 과정은 보통 RAM 메모리에서 처리됩니다. 왜냐하면 DB를 거치면 느립니다.

### 5️⃣ WebSocket 데이터 흐름

채팅 예시 흐름
```
사용자 A  
   │  
   │  메시지 전송  
   ▼  
WebSocket 서버  
   │  
   │ 메모리에 저장  
   │  
   ▼  
사용자 B  
사용자 C  
사용자 D
```

실제 내부 흐름
```
Browser A  
   │  
   │ send()  
   ▼  
WebSocket Server  
   │  
   │ RAM (메모리)  
   │  
   │ broadcast  
   ▼  
Browser B  
Browser C  
Browser D
```

2️⃣ `[서버 코드 작성]` WebSocket 서버 만들기 : 
파일명 예시: `websocketsServer.py`
```python
from fastapi import FastAPI, WebSocket
from fastapi.responses import HTMLResponse

app = FastAPI()

@app.websocket("/ws") # 클라이언트는 ws://localhost:8000/ws 로 연결
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept() # 클라이언트의 WebSocket 연결 요청을 수락
    while True:
    
	    # 클라이언트로부터 텍스트 메시지를 기다림 (await → 비동기 처리)
        data = await websocket.receive_text()
		
		# 받은 메시지를 다시 클라이언트에게 전송 (Echo 방식)
        await websocket.send_text(f"Message text was: {data}")
```
- `/ws` 경로로 클라이언트가 WebSocket 연결 요청
- 연결 수락 후, 클라이언트 메시지를 받아서 다시 응답(echo) 전송

`[HTML 클라이언트 코드 작성]` WebSocket 클라이언트 구현
같은 서버 파일에 HTML 문자열 추가  
(`websocketsFullCode.py` 형태로 작성 가능)
```python
html = """
<!DOCTYPE html>
<html>
  <head><title>Chat</title></head>
  <body>
    <h1>WebSocket Chat</h1>
    <form action="" onsubmit="sendMessage(event)">
        <input type="text" id="messageText" autocomplete="off"/>
        <button>Send</button>
    </form>
    <ul id='messages'></ul>

    <script>
        var ws = new WebSocket("ws://localhost:8000/ws");

        ws.onmessage = function(event) {
            var messages = document.getElementById('messages');
            var message = document.createElement('li');
            var content = document.createTextNode(event.data);
            message.appendChild(content);
            messages.appendChild(message);
        };

            var input = document.getElementById("messageText");
            ws.send(input.value);
            input.value = '';
            event.preventDefault();
        }
    </script>
  </body>
</html>
"""
```

파일 구조

`main.py`
```python
from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.responses import HTMLResponse

# FastAPI 앱 생성
app = FastAPI()

# -----------------------------
# HTML 클라이언트 코드
# 브라우저에서 채팅 UI 역할
# -----------------------------
html = """
<!DOCTYPE html>
<html>
<head>
    <title>FastAPI WebSocket Chat</title>
</head>
<body>

<h1>WebSocket Chat</h1>

<!-- 사용자 이름 입력 -->
<input type="text" id="username" placeholder="username">

<br><br>

<!-- 메시지 입력 -->
<form onsubmit="sendMessage(event)">
    <input type="text" id="messageText" autocomplete="off">
    <button>Send</button>
</form>

<ul id='messages'></ul>

<script>

    // FastAPI WebSocket 서버 연결
    var ws = new WebSocket("ws://127.0.0.1:8000/ws");

    // 서버에서 메시지 받으면 화면에 출력
    ws.onmessage = function(event) {
        var messages = document.getElementById('messages');

        var message = document.createElement('li');
        var content = document.createTextNode(event.data);

        message.appendChild(content);
        messages.appendChild(message);
    };

    // 메시지 전송 함수
    function sendMessage(event) {

        var username = document.getElementById("username").value;
        var input = document.getElementById("messageText");

        // JSON 형식 메시지 생성
        var payload = {
            username: username,
            message: input.value
        };

        // 서버로 메시지 전송
        ws.send(JSON.stringify(payload));

        input.value = '';
        event.preventDefault();
    }

</script>

</body>
</html>
"""


# -----------------------------------------
# WebSocket 연결 관리 클래스
# 현재 접속 중인 사용자 관리
# -----------------------------------------
class ConnectionManager:

    def __init__(self):
        # 현재 접속한 WebSocket 목록
        self.active_connections = []

    async def connect(self, websocket: WebSocket):

        # WebSocket 연결 허용
        await websocket.accept()

        # 접속 목록에 추가
        self.active_connections.append(websocket)

    def disconnect(self, websocket: WebSocket):

        # 연결 종료 시 목록에서 제거
        self.active_connections.remove(websocket)

    async def broadcast(self, message: str):

        # 현재 접속한 모든 사용자에게 메시지 전송
        for connection in self.active_connections:
            await connection.send_text(message)


# ConnectionManager 객체 생성
manager = ConnectionManager()


# -----------------------------------------
# 기본 페이지
# 브라우저에서 채팅 UI 열기
# -----------------------------------------
@app.get("/")
async def get():
    return HTMLResponse(html)


# -----------------------------------------
# WebSocket 채팅 엔드포인트
# -----------------------------------------
@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):

    # 사용자 접속 처리
    await manager.connect(websocket)

    try:

        # 접속 알림
        await manager.broadcast("새 사용자가 입장했습니다.")

        while True:

            # 클라이언트 메시지 수신
            data = await websocket.receive_json()

            username = data.get("username", "anonymous")
            message = data.get("message", "")

            # 메시지를 모든 사용자에게 전송
            await manager.broadcast(f"{username}: {message}")

    except WebSocketDisconnect:

        # 연결 종료 시 처리
        manager.disconnect(websocket)

        await manager.broadcast("한 사용자가 나갔습니다.")
```
