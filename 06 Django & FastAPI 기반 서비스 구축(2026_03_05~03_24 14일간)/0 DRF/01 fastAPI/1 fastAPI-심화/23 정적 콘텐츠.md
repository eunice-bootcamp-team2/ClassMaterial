정적 파일(static files)이란 이미지, CSS, JavaScript, 텍스트, 문서 등 서버에서 고정된 형태로 제공되는 파일들을 말합니다. 사용자의 요청에 따라 내용이 바뀌지 않고 항상 동일한 파일을 그대로 전달하는 것이 특징입니다.

FastAPI에서 Static Files 사용하는 방법

📁 디렉토리 구조
```
project/
├── main.py
├── template/
│   └── index.html
└── static/
    ├── styles/
    │   └── styles.css
    ├── scripts/
    │   └── index.js
    └── images/
        └── logo.png
```

WSL에서 현재 디렉토리를 Windows 파일 탐색기로 여는 명령어:
```bash
explorer.exe .
```
경로에 image파일을 넣습니다.

예제 코드 `main.py`
```python
from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse
from fastapi.templating import Jinja2Templates
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# 정적파일 제공 설정 (CSS, JS 등)
app.mount("/static", StaticFiles(directory="static"), name="static")

# 템플릿 디렉토리 설정
templates = Jinja2Templates(directory="template")

# HTML 페이지 렌더링
@app.get("/", response_class=HTMLResponse)
async def read_index(request: Request):
    return templates.TemplateResponse("index.html", {"request": request, "title": "FastAPI HTML 페이지"})
```

static/template/index.html
```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>{{ title }}</title>
    <link rel="stylesheet" href="{{ url_for('static', path='styles/styles.css') }}">
    <script src="{{ url_for('static', path='scripts/index.js') }}" defer></script>
</head>
<body>
    <header>{{ title }}</header>

    <div class="container">
        <h2>FastAPI + HTML + Static 연습</h2>
        <p>이 페이지는 FastAPI의 정적파일, 템플릿, JavaScript를 연동하여 만들어진 샘플입니다.</p>

        <ul>
            <li>Jinja2 템플릿으로 HTML 렌더링</li>
            <li>정적 파일 (CSS, JS, 이미지) 연동</li>
            <li>깔끔한 UI 디자인</li>
        </ul>

        <img src="{{ url_for('static', path='images/logo.png') }}" alt="로고 이미지">

        <a href="#" class="button" onclick="showTime()">현재 시간 보기</a>

        <p id="output" style="margin-top: 20px; font-weight: bold;"></p>
    </div>

    <footer>&copy; 2025 FastAPI 예제 사이트</footer>
</body>
</html>
```

static/scripts/index.js
```js
function showTime() {
    const now = new Date();
    const output = document.getElementById("output");
    output.textContent = "📅 현재 시간: " + now.toLocaleString();
}
```

static/images/logo.png 이 경로에 로고파일을 저장합니다.

실행하고 결과 확인
```
uvicorn main:app --reload
```
