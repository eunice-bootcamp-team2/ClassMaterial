`1)` 엔드포인트 등록 (라우팅)

FastAPI
- `src/routers/articles_router.py`에서 
- `@router.get("/", ...)`
- `@router.get("/{id}", ...)`
- `src/app.py`에서 `app.include_router(articles_router, prefix="/articles")`
    - 최종 URL:
        - `GET /articles/`
        - `GET /articles/{id}`
            
DRF라면
- `views.py`에 `ArticleViewSet` 또는 `ArticleList`/`ArticleDetail` 작성
- `urls.py`에서 `DefaultRouter`로 등록 또는 `path("articles/", ...)`, `path("articles/<int:id>/", ...)`
    
---
`2)` 요청 파라미터 해석 & 검증
FastAPI
- `read_articles()`는 의존성 파라미터로 `
- `articles: list[Article] = Depends(get_articles)`를 받음.
    - 즉, `get_articles()`가 먼저 실행되면서 쿼리 파라미터를 자동 파싱/검증:
        - `skip: int = 0`, `limit: int = 100`
        - `order_by: ArticleOrderBy` (Enum: title/created_at/updated_at)
        - `sort: Sort` (Enum: asc/desc)
    - 타입/Enum 검증 실패 시 FastAPI가 422 자동 응답.
- `read_article()`도 같은 방식으로 `id: int`(경로 파라미터) → `get_article_by_id(id, db)` 호출
    
DRF라면
- `request.query_params.get("skip")` 처럼 문자열로 직접 꺼내 파싱하거나,
- `django-filter`/`OrderingFilter`/맞춤 QuerySerializer로 검증
- 경로 파라미터는 `path("articles/<int:id>/", ...)`로 변환되어 View 메서드에서 `self.kwargs["id"]`로 접근
    
---
`3)` 의존성 주입(Depends) → 오퍼레이터 실행
FastAPI
- `Depends(article_operator.get_articles)`  
    → FastAPI가 의존성 체인을 해석해 `get_articles()`를 먼저 실행
- `get_articles()` 내부에서 다시 `db: Session = Depends(get_db)`를 주입  
    → 요청마다 SQLAlchemy `Session`을 열고, 함수 종료 시 정리
    
DRF라면
- 의존성 주입은 없음. DB 세션은 Django가 요청 단위로 관리.
- View에서 곧바로 ORM 호출하거나, 서비스 레이어(함수)를 직접 호출하는 패턴을 씀.
    
---
 `4)` DB 접근 (ORM)
FastAPI
- `db.query(article_model.Article)`로 SQLAlchemy 쿼리
- 정렬: `order_by(text("%s %s" % (order_by.value, sort.value)))`
- 페이징: `.limit(limit).offset(skip)`
- 단건: `.filter(...).first()`
    
> 메모: 정렬은 `text()` 대신  
> `col = getattr(Article, order_by.value)` → `col.desc()`/`col.asc()`를 쓰면 더 안전하고 인덱스도 잘 탑니다.

DRF라면
- `Article.objects.all()`(Django ORM)
- 정렬: `?ordering=updated_at` + `OrderingFilter` 또는 `queryset.order_by(...)`
- 페이징: 전역/클래스별 Pagination(`LimitOffsetPagination`, `PageNumberPagination`)
- 단건: `get_object_or_404(Article, pk=id)`
    
---
`5)` 예외 처리
FastAPI
- 없으면 `HTTPException(status_code=404, detail="Not found")` 발생 → JSON으로 404 응답
    
DRF라면
- `get_object_or_404` 사용 또는 `NotFound` 예외 발생
- 리스트에서 빈 결과는 DRF 기본은 200 + 빈 배열(404로 바꾸려면 오버라이드 필요)
    - 현재 FastAPI 코드는 리스트가 비면 404를 던지는데, REST 관행상 빈 배열 200을 더 흔히 씁니다(참고).
        
---
`6)` 응답 직렬화 (스키마/시리얼라이저)
FastAPI
- 라우터에 `response_model=article_schema.Article`(또는 `list[Article]`)
- 오퍼레이터가 SQLAlchemy 객체를 반환해도  
    Pydantic 모델(`from_attributes=True`일 것)이 필요한 필드만 뽑아 JSON 변환
- 스키마가 Swagger에 자동 문서화(필드 구조, 타입, 예시)
    
DRF라면
- `serializer = ArticleSerializer(queryset, many=True)` → `return Response(serializer.data)`
- Serializer가 필드/밸리데이션/중첩 구조 정의, Browsable API & OpenAPI 스키마 생성
    
---
`7)` 문서화(Swagger/OpenAPI)
FastAPI
- 엔드포인트 + 스키마 + 의존성의 파라미터 시그니처가 **자동**으로 `/docs`에 반영
    - 의존성 함수(`get_articles`)에 정의된 `skip/limit/order_by/sort`가 문서에 파라미터로 나타남
        
DRF라면
- 기본 스키마 생성도 가능하지만, 보통 `drf-spectacular`/`drf-yasg`로 풍부한 OpenAPI 문서화를 사용
- 쿼리 파라미터는 `django-filter`/OpenApiParameter 수동 정의로 명확히 표시
    
---
##### 한 줄 요약 매핑
| FastAPI 코드 요소           | DRF에서 보통 어디에?                            |
| ----------------------- | ---------------------------------------- |
| `@router.get(...)`      | `APIView`/`GenericAPIView`/`ViewSet` 메서드 |
| `Depends(get_articles)` | View 내부에서 서비스/헬퍼 함수 호출                   |
| `Depends(get_db)`       | (없음) Django가 요청 단위 DB 세션 관리              |
| SQLAlchemy 쿼리           | Django ORM 쿼리셋                           |
| `HTTPException(404)`    | `get_object_or_404`, `NotFound`          |
| `response_model=Schema` | `Serializer`로 `.data` 응답                 |
| Swagger 자동 파라미터 노출      | drf-spectacular 등의 OpenAPI 확장            |

`src/routers/articles_router.py`
```python
from fastapi import APIRouter, Depends

from src.schemas import article_schema
from src.operators import article_operator

router = APIRouter(tags=["Articles"])


@router.get("/", 
            response_model=list[article_schema.Article])
async def read_articles(articles: list[article_schema.Article] = Depends(article_operator.get_articles)):
    return articles


@router.get("/{id}", 
            response_model=article_schema.Article)
async def read_article(article: article_schema.Article = Depends(article_operator.get_article_by_id)):
    return article
```

`src/app.py`
```python
from src.routers.articles_router import router as articles_router
app.include_router(articles_router, prefix="/articles")
```

`src/operators/article_operator.py`
```python
from enum import Enum

from fastapi import Depends, HTTPException, status

from sqlalchemy.orm import Session
from sqlalchemy.sql import text
from src.models import article_model

from src.dependencies.database import get_db


class ArticleOrderBy(str, Enum):
    title = "title"
    created_at = "created_at"
    updated_at = "updated_at"

class Sort(str, Enum):
    asc = "asc"
    desc = "desc"


def get_article_by_id(id: int, db: Session = Depends(get_db)):
    article = db.query(article_model.Article).filter(article_model.Article.id == id).first()
    if not article:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Not found")
    return article

# 페이지네이션 관련 속성 기본값은 0 최대 100개 
def get_articles(skip: int = 0, limit: int =100, order_by: ArticleOrderBy = ArticleOrderBy.updated_at, sort: Sort = Sort.desc, db: Session = Depends(get_db)):
    articles = db.query(article_model.Article).order_by(text("%s %s" % (order_by.value, sort.value))).limit(limit).offset(skip).all()
    if not articles:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Not found")
    return articles
```
