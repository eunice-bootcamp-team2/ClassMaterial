JWT란?
JWT (JSON Web Token) 는 이런 인증 토큰을 JSON 형식으로 만들어 암호화한 것입니다. 
구조는 3가지 조각으로 나뉩니다:
```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.
eyJzdWIiOiJ1c2VyMSIsImV4cCI6MTYzNzk5Njk4Mn0.
7kAgCj...암호화된서명...
```

`Header`	토큰의 종류, 사용한 암호화 알고리즘
`Payload`	사용자 정보 (ex: id, 이름, 권한 등)
`Signature`	암호화된 서명 (위조 방지용)

###### JWT vs 일반 토큰 (Session Token 등) 비교
| 항목         | 일반 토큰 (세션 기반)        | JWT (JSON Web Token)     |
| ---------- | -------------------- | ------------------------ |
| 저장 위치      | 서버 메모리 (세션 스토리지)     | 클라이언트에 저장                |
| 서버에서 토큰 관리 | 필요함 (세션 테이블 유지)      | 필요 없음 (Stateless)        |
| 구조         | 단순 문자열 (의미 없음)       | 구조화된 JSON + 서명           |
| 위변조 방지     | 불가능 (서명 없음)          | 가능 (서명 포함, 변조 시 검증 실패)   |
| 확장성        | 서버가 커지면 세션 동기화 문제 생김 | 수평 확장에 유리 (Stateless 구조) |
| 단점         | 서버 메모리 부담, 유지 필요     | 탈취당하면 누구나 사용 가능 (주의 필요)  |

보안 측면에서 JWT는 왜 유리할까?
1. 위조 방지:  
    JWT는 서명이 포함되어 있어, 누가 내용을 바꾸면 검증에 실패합니다.
    
2. 서버가 기억 안 해도 됨:  
    사용자가 보내는 토큰만 있으면, 다시 로그인 없이 확인 가능.  
    서버는 "이 토큰이 위조된 게 아닌지만" 확인하면 됨.
    
3. 토큰 안에 정보 포함 가능:  
    예: `{"username": "eunice", "role": "admin"}`  
    → 권한, 유저 정보도 포함 가능

JWT는 "서명된 JSON 토큰"으로, 서버가 사용자를 식별하고 권한을 판단할 수 있게 해주는 위조 불가능한 인증표입니다.  
일반 토큰보다 보안성과 확장성이 뛰어나며, 서버에 상태를 저장하지 않아도 됩니다.

###### Django나 Google API, Amazon Cloud에서 내려받는 **보안키**(비밀 키, API 키 등)와는 다른 역할:
| 항목            | JWT                        | 보안 키(API Key / Secret Key)           |
| ------------- | -------------------------- | ------------------------------------ |
| 정의            | 사용자 정보를 담고 있는 토큰 (디지털 신분증) | 서버끼리 통신 시, 인증을 위한 비밀키                |
| 형태            | `aaaaa.bbbbb.ccccc` 같은 문자열 | `sk_test_xxxxx` / `AIzaSy...` 같은 문자열 |
| 누가 만듬         | 서버가 사용자 로그인 후 발급           | 서비스 제공자(Google, AWS 등)가 발급           |
| 용도            | 로그인된 유저의 상태를 확인            | 외부 API 인증(예: Stripe, Google Maps 등)  |
| 보관 위치       . | 클라이언트(브라우저/앱)에 저장          | 서버(환경변수 등)에만 저장                      |
| 예시            | FastAPI에서 로그인 후 JWT 발급     | `.env`에 `SECRET_KEY=xxxxx` 등 저장      |

JWT 관련 설정 (`auth.py`)
- 로그인 정보 확인 (`authenticate_user`)
- 비밀번호 암호화 (`get_password_hash`)
- JWT 토큰 생성 (`create_access_token`)
- JWT 토큰 검증 (`get_current_user`)
```python
# JWT 관련 에러 및 토큰 인코딩/디코딩 함수 제공
from jose import JWTError, jwt

# 토큰 만료 시간을 위한 datetime 도구
from datetime import datetime, timedelta

# 비밀번호 암호화/검증 기능을 위한 라이브러리
from passlib.context import CryptContext

# FastAPI에서 예외처리 및 의존성 주입 관련 도구
from fastapi import HTTPException, Depends, status

# OAuth2 인증을 위한 의존성 (토큰 방식 인증을 구현할 때 사용)
from fastapi.security import OAuth2PasswordBearer

# 시간을 다룰 때 쓰는 모듈 중 일부를 가져오는 코드
from datetime import datetime, timezone

# ----------------------
# 1. 기본 설정
# ----------------------

# 토큰 암호화 비밀 키 (실제 서비스에서는 .env 환경변수로 관리해야 안전)
SECRET_KEY = "mysecretkey" # 발급된 보안키를 여기에 저장

# 사용할 암호화 알고리즘 (HS256: 대칭키 방식)
ALGORITHM = "HS256"

# 토큰 유효 시간: 30분
ACCESS_TOKEN_EXPIRE_MINUTES = 30


# ----------------------
# 2. 비밀번호 해싱 및 검증 설정
# ----------------------

# bcrypt 해시 알고리즘을 사용할 비밀번호 암호화 컨텍스트 생성
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")


# ----------------------
# 3. OAuth2PasswordBearer 설정
# ----------------------

# 클라이언트가 토큰을 헤더로 보낼 때, 그 토큰을 추출할 수 있도록 설정
# tokenUrl="token"은 /token 엔드포인트에서 토큰을 발급한다는 의미
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")


# ----------------------
# 4. 비밀번호 관련 함수
# ----------------------

# 사용자가 입력한 비밀번호와 DB에 저장된 해시값을 비교
def verify_password(plain_password, hashed_password):
    return pwd_context.verify(plain_password, hashed_password)

# 사용자의 비밀번호를 bcrypt 방식으로 해시 처리하여 저장
def get_password_hash(password):
    return pwd_context.hash(password)


# ----------------------
# 5. 유저 인증 관련 로직 (임시 유저 DB 사용)
# ----------------------

# 임시 사용자 DB (실제 앱에서는 DB 모델로 교체해야 함)
fake_user_db = {
    "testuser": {
        "username": "testuser",
        "hashed_password": get_password_hash("test123")  
        # 평문 비밀번호를 해시해서 저장
    }
}

# 사용자 인증 함수: 입력한 아이디/비번이 fake_user_db와 일치하는지 확인
def authenticate_user(username: str, password: str):
    user = fake_user_db.get(username)  # 사용자 정보 가져오기
    if not user:
        return False  # 사용자 없음
    if not verify_password(password, user["hashed_password"]):
        return False  # 비밀번호 불일치
    return user  # 인증 성공 시 사용자 정보 반환


# ----------------------
# 6. JWT 토큰 생성 함수
# ----------------------

# JWT 토큰 생성: 사용자 정보(data)를 받아 유효시간과 함께 암호화된 토큰을 생성
def create_access_token(data: dict, expires_delta: timedelta = None):
    to_encode = data.copy()  # 원본 딕셔너리를 복사해서 수정
    expire = datetime.now(timezone.utc) + (expires_delta or timedelta(minutes=15))  # 만료 시간 계산
    to_encode.update({"exp": expire})  # 토큰에 만료 시간 추가
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)  # JWT 토큰 생성 및 리턴


# ----------------------
# 7. 토큰을 통해 현재 사용자 정보 가져오기 (API 보호 시 사용)
# ----------------------

# 토큰이 유효한지 확인하고, 사용자 정보를 추출하여 리턴
def get_current_user(token: str = Depends(oauth2_scheme)):
    try:
        # 토큰 디코딩 및 검증 (유효하지 않거나 변조된 토큰은 예외 발생)
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        
        # 토큰에서 username(sub)을 꺼냄
        username: str = payload.get("sub")

        # username이 없으면 유효하지 않은 토큰으로 간주
        if username is None:
            raise HTTPException(status_code=401, detail="Invalid token")
        
        # 성공적으로 사용자명 추출하면, 딕셔너리 형태로 리턴
        return {"username": username}
    
    # 토큰 디코딩/검증 중 에러가 발생하면 인증 실패 예외 처리
    except JWTError:
        raise HTTPException(status_code=401, detail="Invalid token")

```

FastAPI 앱 구성 (`main.py`)
```python
# FastAPI 주요 모듈 불러오기
from fastapi import FastAPI, Depends, HTTPException, status

# OAuth2 기반 로그인 폼 처리를 위한 클래스
from fastapi.security import OAuth2PasswordRequestForm

# 인증 관련 함수들 (auth.py에서 직접 만든 함수 import)
from auth import authenticate_user, create_access_token, get_current_user

# 토큰 만료 시간 설정을 위한 모듈
from datetime import timedelta

# FastAPI 앱 인스턴스 생성
app = FastAPI()


# ----------------------------
# 로그인 엔드포인트
# ----------------------------
@app.post("/token")
def login(form_data: OAuth2PasswordRequestForm = Depends()):
    """
    사용자로부터 username/password를 받아 JWT access_token을 발급
    Swagger UI에서는 자동으로 grant_type 등도 포함된 POST요청이 이뤄짐.
    """

    # 사용자 인증 수행 (ID, PW 일치 확인)
    user = authenticate_user(form_data.username, form_data.password)

# 인증 실패 시 예외 발생 (401 Unauthorized 아님. 일부러 400으로 처리)
    if not user:
        raise HTTPException(
            status_code=400,
            detail="Incorrect username or password"
        )

    # 인증 성공 시, access_token(JWT)을 생성 (만료시간: 30분)
    access_token = create_access_token(
        data={"sub": user["username"]},  
        # "sub"는 subject(토큰 소유자)의 약자
        
        expires_delta=timedelta(minutes=30)
    )

    # 토큰 응답 반환 (token_type은 "bearer"로 고정)
    return {
        "access_token": access_token,
        "token_type": "bearer"
    }


# ----------------------------
# 인증이 필요한 보호된 API
# ----------------------------
@app.get("/protected")
def read_protected(current_user: dict = Depends(get_current_user)):
    """
    JWT 토큰을 가지고 있어야 접근 가능한 보호된 API입니다.
    현재 로그인한 사용자 정보(current_user)를 토큰에서 가져와 인증을 확인합니다.
    """

    # 인증된 사용자를 위한 응답 메시지 반환
    return {
        "msg": f"Hello {current_user['username']}, you're authenticated!"
    }
```

```python
# users/api_views.py

from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework import status
from django.contrib.auth import authenticate
from rest_framework.permissions import IsAuthenticated
from .serializers import UserLoginSerializer

from rest_framework_simplejwt.tokens import RefreshToken

# 로그인 API
class LoginView(APIView):
    def post(self, request):
        serializer = UserLoginSerializer(data=request.data)
        serializer.is_valid(raise_exception=True)
        user = authenticate(
            username=serializer.validated_data["username"],
            password=serializer.validated_data["password"]
        )

        if not user:
            return Response({"detail": "Invalid credentials"}, status=status.HTTP_400_BAD_REQUEST)

        refresh = RefreshToken.for_user(user)
        return Response({
            "access_token": str(refresh.access_token),
            "refresh_token": str(refresh),
            "token_type": "bearer"
        })


# 보호된 API
class ProtectedView(APIView):
    permission_classes = [IsAuthenticated]

    def get(self, request):
        return Response({
            "msg": f"Hello {request.user.username}, you're authenticated!"
        })
```
